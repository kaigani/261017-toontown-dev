### C41-R2-01 - P2 - idle unauthenticated clients exclude valid new requests

Clause: ADR-0022 decision 2 resource bounds; A2 admission-cap availability requirement.

Reproduction: fill the unauthenticated cap with idle sockets, then send a complete correctly authenticated request on a fresh socket. At `http.rs:692` admission is attempted before reading any header or token, so it returns 503. At defaults, 16 local idle sockets can deny every fresh authenticated connection for ten seconds; replenishing them sustains denial. Existing admitted streams are not claimed to stop.

Permanent reproduction: `cargo test -p tt-mcp --test c41_r2_review idle_unauthenticated_clients_leave_authenticated_service_available --locked`. **Fails at 43508ba**. Uses cap 1 and head deadline 2 s, synchronizes on an observed 503, sends the valid request, and measures the operation with Instant (under one second). Expected authenticated session lookup 404; observed 503. Builder must make the test pass with its body unchanged. Evidence: `a2.txt`.

Required: a bounded admission design that preserves authenticated service under idle unauthenticated saturation. Observed: the smaller cap denies all new clients before they can identify themselves. Fix direction: reserve bounded parsing capacity for complete heads/credentials and prevent idle clients from monopolizing it. Owner: C4.1 HTTP transport.

### C41-R2-02 - P2 - refusals bypass connection cap with one lingering thread per socket

Clause: ADR-0022 decision 2 admission bounds; A3 refusal-denial-of-service requirement.

Reproduction: `http.rs:688` creates a thread before checking the open counter. A failed admission returns `busy()` (`:716`), which writes 503 then calls `linger_close()` (`:734`) without owning any open slot. An unauthenticated local client can keep arbitrarily many such refusal sockets open and replenish them. Individual lifetimes are bounded, simultaneous thread/socket count is not.

Permanent reproduction: `cargo test -p tt-mcp --test c41_r2_review refused_connections_do_not_escape_thread_cap --locked -- --test-threads=1`. **Fails at 43508ba**, Windows. With cap 1, 64 simultaneous refusal sockets add 64 process threads in 163.2147 ms (earlier run 188.1946 ms); expected growth at most 16 including measurement/runtime slack. Instant verifies capture inside the one-second linger interval; no sleeps. Test uses OS process thread count. Builder must pass its body unchanged. Evidence: `a3.txt`.

Required: admission bounds cover all accepted sockets and their cleanup work. Observed: refusal itself provides an uncapped thread-allocation path. Fix direction: acquire capacity before spawning and perform refusal/lingering cleanup through a bounded mechanism. Owner: C4.1 HTTP transport.

### C41-R2-03 - P2 - session expires during authenticated body reception

Clause: ADR-0022 decision 2 O-7: expiry only with no request in flight.

Reproduction: `post` checks the session at `http.rs:843`, then reads the body before touching last_seen or registering a request stream (`:869` onward). `expire` (`:747`) therefore sees an idle session during body reception and removes it. A request begun just before the default thirty-minute idle boundary can fail despite having passed authentication and session validation; request deadline is sixty seconds. This is automatic expiry, not explicit DELETE.

Permanent reproduction: `cargo test -p tt-mcp --test c41_r2_review session_is_not_expired_while_authenticated_body_is_in_flight --locked`. **Fails at 43508ba**: initialize; send valid authenticated head plus first body byte; use Instant to wait 600 ms under a 300 ms idle policy and a 3 s request deadline; send the remaining notification. Expected 202, observed 404. No sleeps; only public configurable durations. Builder must pass its body unchanged. Evidence: `a3.txt`.

Required: protect a named session from automatic expiry throughout an admitted request, including bounded body reception. Fix direction: acquire an in-flight lifetime guard under the map lock before reading the body, release on every return, and avoid a gap before registering the response route. Owner: C4.1 HTTP transport.
