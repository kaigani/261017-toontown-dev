## 2. Declared edits

1. **Builder tests updated (cause in each):**
   - `c23_layers.rs::optimize_merges_only_where_appearance_cannot_change`: a fill inside a painted zone no longer
     merges (R1-04; the zone would split along a seam); expectations 2 → 1 merge, layer list updated; pixel-hash
     equality added for every accepted merge.
   - `c23_colour.rs`: the stale-zone code `drawing.staleZoneId` → `colour.staleZoneId` (R1-09); the protection test's
     second pair Sky → Ink becomes Ink → Sky, because under R1-13 a map whose only effective pair is protected refuses.
   - `c23_contracts.rs`: rewritten as described under R1-14 (cases, `prelude`, read-back now includes stored stroke
     matrices so mapping changes are visible).
   - `c23_render.rs`: tile-off upright checks unchanged; new golden `texture-stretch-inset`; writes the CI artifact.
   - New builder tests: `c23_watchdog.rs`, `crates/vector/tests/c23_predicates.rs`, Smooth bound test in
     `c23_strokeops.rs`.
2. **Goldens:** `crates/executor/tests/goldens/c23_render.json` gains `texture-stretch-inset` (R1-06: a tile-off image
   smaller than its zone, transparent around it). **No existing hash changed:** the earlier goldens' images cover their
   zones, so the clip removes nothing from them. PNG added under `reviews/evidence/M2-C2.3/goldens/`.
3. **Dependencies/features:** `tt-vector` gains the dev-only feature `test-hooks` (the watchdog spin), enabled only
   from `tt-executor`'s dev-dependencies, like `tt-persist`'s. No new crate in `Cargo.lock`.
4. **CI:** `.github/workflows/ci.yml` copies `target/evidence/c23-render` into each `check` job's artifact.
5. **Deterministic shutdown (found by CI on macOS):** dropping the last `ExecutorHandle` now waits (bounded, 10 s) for
   the document thread to drop its state, so the project's lock and files are released when the drop returns. Before,
   shutdown was only queued, and `c23_r1_contracts::five_independent_mutations_are_atomic_reversible_and_persistent`
   could race the lock release with its `remove_dir_all` (`DirectoryNotEmpty`, run 41317054043, macOS).

   10 000-operation history oracles (`ten_thousand_history_operations_match_independent_content_oracle_and_replay` in
   `c12_r1_stress`, `c12_r3_stress`, `c13_r3_history_r1`, `c13_r3_history_r3`, `c14_r3_history_r1`,
   `c14_r3_history_r3`; about 13 min in debug on Windows) now run in release in the `headless` job, beside the
   existing `c21_history` oracles, with their assertions unchanged; `check` skips only that test name (the step keeps its
   name, so the reviewer audits that read CI logs still find it).
