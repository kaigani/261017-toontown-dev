# C4.1 — Keyboard-only use and visible focus (≈ 6 min)

Spec: 01 §8 (keyboard), §9 (help and accessibility of the shell). Found uncovered in round 1 (C41-R1-22).

Do not touch the mouse or trackpad after step 1.

1. Start Toontown and click once in the start screen.
2. Press **Tab** repeatedly → focus moves through New project (Name, Format, Frame rate, Camera width, Camera height,
   Create), Recent projects (Open other…), Learn, Show at start-up, in reading order; every focused control shows a
   visible focus ring.
3. Focus **Name**, type `Keyboard`, press **Return** → a project opens.
4. Press **Ctrl+,** (macOS **⌘,**) → Preferences opens and the focus is inside it (the first category or the search
   field shows the ring). **Tab** cycles inside the dialog only; **Esc** closes it and the focus returns where it was.
5. **Alt** (Windows) → the menu bar takes the focus; arrow keys move through the menus; **Esc** leaves it.
6. Open File › Project Properties… with the keyboard; change a value; **Return** applies, **Esc** cancels.
