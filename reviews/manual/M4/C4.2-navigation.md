# C4.2 — Navigation in the Drawing view (≈ 6 min)

Spec: 02 §4.3; 01 §6.5; SI-122, SI-123.

1. File › New, Drawing workspace, draw a few strokes.
2. Mouse wheel over a stroke → zooms in steps of the 02 §4.3 ladder keeping the point under the pointer still.
3. Trackpad pinch (macOS and precision touchpads) → zooms; two-finger scroll → pans; note what rotate does (rotation is
   only through View › Rotate, SI-123).
4. Keyboard zoom in / out (the keymap's zoom keys) → table steps (01 §6.5); View › Reset View → back to 100 %.
5. Zoom tool: click → steps in; drag a rectangle → fits it; Grabber: drag → pans.
6. Space-bar or the Grabber's temporary override while drawing → no stroke is made while panning.
7. Do steps 2-5 on Windows and on macOS.
