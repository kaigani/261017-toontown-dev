# C4.4a — Open Recent's full path (≈ 3 min)

Spec: 01 §3.3 line 190 ("Each menu entry shows the project name; the full path is shown in the status bar or
tooltip"); ruling D-48 item 8; `reviews/M4-design-panels.md` §13. The D-39 table checks the Windows status bar with
real input and the menu model's path on both OSes; the macOS tool tip needs a person.

1. Start Toontown. Create a project and **File › Save As…** it as `Recent One` in a folder of your choice. Repeat with a
   second project, `Recent Two`, in another folder.
2. **macOS:** open **File › Open Recent**, rest the pointer on **Recent Two** for two seconds → a tool tip shows the
   full path of `Recent Two.animpkg`. Do the same on **Recent One** → its own full path.
3. **Windows:** open **File › Open Recent** and move the highlight over the entries (pointer or arrow keys) → the
   status bar's left end shows the highlighted entry's full path. Highlight **Clear** → the line is empty. Press
   **Esc** until the menu closes → the line shows what it showed before.
4. Neither the highlight nor the tool tip opens anything: the title still names the current project.
