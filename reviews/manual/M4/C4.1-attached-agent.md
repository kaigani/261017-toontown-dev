# C4.1 — A real agent in attached mode (≈ 8 min)

Spec: 11 §3, §4, §6.4; ADR-0022.

1. Preferences › Agent access: turn on **agent.server.enabled**, OK. The discovery file
   (`%APPDATA%\Toontown\Settings\agent-discovery.json` / `~/Library/Application Support/Toontown/Settings/…`) names the
   endpoint and the token.
2. Connect an MCP client that supports Streamable HTTP to the endpoint with `Authorization: Bearer <token>`. The status
   bar shows the agent indicator with the client's name.
3. Ask the agent to create a project and change the workspace → the window follows live; while it works the indicator
   shows the acting state.
4. Open Preferences (a modal dialog) and ask the agent to change the project → it waits, then reports `ui.busy`
   (about 10 s). Close Preferences and ask again → it succeeds.
5. From the indicator: **Pause** → the agent's next call waits and fails with `agent.paused`; **Resume**; **Stop** →
   the session ends.
6. Turn the server off in Preferences → the client is disconnected.
