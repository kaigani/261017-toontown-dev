# C4.1 — A real agent in attached mode (≈ 8 min)

Spec: 11 §3, §4, §6.4; ADR-0022.

Prerequisites: Python 3.11 or later, and in a fresh virtual environment the official MCP SDK:

```
python -m venv .venv-agent
.venv-agent/bin/pip install "mcp==2.0.0"          # Windows: .venv-agent\Scripts\pip install "mcp==2.0.0"
```

1. Preferences › Agent access: turn on **agent.server.enabled**, OK. The discovery file
   (`%APPDATA%\Toontown\Settings\agent-discovery.json` / `~/Library/Application Support/Toontown/Settings/agent-discovery.json`)
   names the endpoint (`http://127.0.0.1:47215/mcp` unless that port was taken) and the token.
2. Save this as `agent.py` and run `.venv-agent/bin/python agent.py "<path of agent-discovery.json>"` (Windows:
   `.venv-agent\Scripts\python agent.py "%APPDATA%\Toontown\Settings\agent-discovery.json"`). It connects over
   Streamable HTTP with the token, then waits for a command line per step below (type the tool and its JSON
   arguments, for example `run_command {"id": "project.create", "params": {"name": "Agent test"}}`; an empty line
   ends it):

   ```python
   import asyncio, json, sys
   import httpx2
   from mcp import ClientSession
   from mcp.client.streamable_http import streamable_http_client

   async def main(path):
       d = json.load(open(path, encoding="utf-8"))
       client = httpx2.AsyncClient(headers={"Authorization": "Bearer " + d["token"]}, timeout=60.0)
       async with client, streamable_http_client(d["endpoint"], http_client=client) as (r, w, *_):
           async with ClientSession(r, w) as s:
               await s.initialize()
               while (line := input("tool args> ").strip()):
                   tool, _, args = line.partition(" ")
                   result = await s.call_tool(tool, json.loads(args or "{}"))
                   print(json.dumps(getattr(result, "structured_content", None), indent=2))

   asyncio.run(main(sys.argv[1]))
   ```

   The status bar shows the agent indicator with the client's name (`mcp`).
3. At the `tool args>` prompt type, one line at a time:
   - `run_command {"id": "project.create", "params": {"name": "Agent test"}}` → the window opens the project "Agent
     test" live;
   - `run_command {"id": "workspace.select", "params": {"name": "Drawing"}}` → the window switches to the Drawing
     workspace. While each call runs the indicator shows the acting state.
4. Open Preferences in the window (**Ctrl+,** / **⌘,**; a modal dialog), then type
   `run_command {"id": "project.properties.set", "params": {"frameRate": 12}}` → the call waits about 10 s, then the
   printed result has `"status": "error"` and `"code": "ui.busy"`. Close Preferences (**Esc**) and type the same line
   again → `"status": "ok"`, and File › Project Properties… shows 12.
5. From the indicator: **Pause** → the agent's next call waits and fails with `agent.paused`; **Resume**; **Stop** →
   the session ends.
6. Turn the server off in Preferences → the client is disconnected.
