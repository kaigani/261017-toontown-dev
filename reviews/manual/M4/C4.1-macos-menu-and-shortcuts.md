# C4.1 — macOS menu and shortcuts (≈ 5 min)

Spec: 01 §5.1 (application menu), §8.2 (platform shortcuts), §8.4 (dispatch); ADR-0021 decision 9 (on macOS the menu
owns its key equivalents, the webview never runs the same key twice).

1. Start Toontown. The first menu is **Toontown** with About, Settings…, Services, Hide, Hide Others, Show All, Quit.
2. Press **⌘,** → the Preferences window opens on General. Press **Esc** → it closes, nothing changed.
3. On the start screen type a name and press **Return** in the Name field → a project opens (title shows the name).
4. Make any change (Window › Panels › History to watch steps), then **⌘Z** → exactly one step is undone (the History
   panel moves one entry, not two). **⇧⌘Z** redoes one step.
5. Open the Edit menu: Undo/Redo name the step ("Undo …"). The View menu shows check marks for Status Bar, Main
   Toolbar, Full Screen.
6. **⌘W** → the unsaved-changes box (Save / Don't Save / Cancel). Choose **Cancel** → the project stays open.
7. **⌘Q** → the same box; choose **Don't Save** → the application quits.
