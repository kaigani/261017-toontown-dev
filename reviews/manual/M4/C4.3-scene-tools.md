# C4.3 — The scene tools by mouse and by pen (≈ 10 min)

Spec: 05 §3.5 (picking, the 3-pixel drag start, nudges), §5.0-§5.2 (Select, Transform, the temporary Select and Skew),
§17; SI-150, SI-151, SI-157; preview note 8 (the live preview).

**Prerequisites** (everything this script assumes; nothing else is needed):

- **A build of the handoff head:** the CI artifact `desktop-Windows` or `desktop-macOS` of the run named in
  `reviews/M4-C4.3b-handoff.md` §1, or a local `pnpm --dir desktop tauri build --no-bundle`.
- **The fixture project** `reviews/manual/M4/fixtures/c43-camera.animpkg`, copied somewhere writable, opened with
  File › Open….
- **An agent client** to choose a scene tool: the one in `C4.1-attached-agent.md`;
  `run_command {"id": "anim.tool.set", "params": {"tool": "select"}}` or `{"tool": "transform"}`.
- **A pen tablet** for step 9 (optional).

1. Select tool. Click Bob → selected. Drag him slowly → he follows the pointer exactly while you drag (the preview), and
   stays where you let go; Edit › Undo shows one "Move Element" step.
2. Drag a corner handle → Bob scales while you drag, about his pivot (his centre in the fixture), by the factor of the
   corner's drag from the opposite corner (SI-150); the preview and the result agree; one "Scale Element" step. Hold
   Shift at a corner → both axes scale equally.
3. Press just outside a corner (the rotation zone) and drag around → Bob turns about his centre while you drag; with
   the constrain modifier he snaps to 15° steps; one "Rotate Element" step.
4. During any drag press Escape → Bob returns to where he was; nothing is added to the undo list.
5. Transform tool. Move Bob → the same, and his position is keyed at the current frame (the Timeline, when it exists,
   shows a key; for now `run_command {"id": "doc.object.get", "params": {"ref": "el_01K7JJN800FWYC1TEZ57XR65SW"}}` shows the key).
6. Drag a skew handle (12 pixels outside the middle of a side) → Bob shears along that side while you drag; one
   "Skew Element" step. With the Transform tool, hold Alt (macOS: Option) and drag from a side's middle → the
   temporary Skew does the same; release Alt → the Transform tool is back.
7. Drag the pivot marker → it moves; Bob does not; one "Move Pivot Element" step.
8. Drag on empty space → a rubber band selects every element it touches; a click on nothing clears the selection.
9. With a pen, repeat steps 1-3 → the same results; light pressure does not change what the tool does.
10. While dragging Bob, ask an agent for a change (see `C4.3-coexistence.md`) → its change waits until you let go.
