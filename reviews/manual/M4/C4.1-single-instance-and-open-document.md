# C4.1 — Single instance and open-document requests (≈ 5 min)

Spec: 01 §1.1 rules 1 and 8.

1. Save a project somewhere (`Test.animpkg`). Quit.
2. Double-click `Test.animpkg` in Finder / Explorer → Toontown starts and opens it (the start screen does not stay).
3. With Toontown running, double-click another saved package → the running window comes to the front and opens it
   (after the unsaved-changes box if the current project is modified); no second window or process appears (Activity
   Monitor / Task Manager shows one `toontown`).
4. Start Toontown again from the Dock / Start menu while it runs → still one process; the window comes to the front.
