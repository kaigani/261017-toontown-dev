# C4.1 — Close a dialog, then use a shortcut (≈ 3 min)

Spec: 01 §8.4 (shortcuts are suspended while a dialog is open), 01 §12.1 rule 8. The round-1 finding C41-R1-01: after a
dialog closed, shortcuts stayed suspended.

1. Open a project (start screen › Create).
2. Window › Panels › History. Note the current entry.
3. Open Preferences (**Ctrl+,** / **⌘,**). Press **Ctrl+Z** (**⌘Z**) inside it → nothing happens to the project.
4. Close Preferences with **Esc**.
5. Make a change (File › Project Properties…, Frame rate 12, OK), then press **Ctrl+Z** (**⌘Z**) at once → the change
   is undone (the shortcut works right after a dialog closed).
6. Repeat step 3-5 closing Preferences with **Cancel** and then with the window's close button.
7. Optional, with the agent client of C4.1-attached-agent.md: after closing Preferences, ask the agent to rename the
   scene → it succeeds immediately (no `ui.busy`).
