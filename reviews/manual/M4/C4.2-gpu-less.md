# C4.2 — The software path on a machine without a GPU (E-C3; ≈ 10 min)

Spec: 06 §6.9 (software path); ADR-0007 decision 5, experiment E-C3.

**Prerequisites** (everything this script assumes; nothing else is needed):

- **A build of the handoff head:** the CI artifact `desktop-Windows` or `desktop-macOS` of the run named in `reviews/M4-C4.2b-handoff.md` §1 (Windows: `default-build/toontown.exe`; macOS: unpack `Toontown-macos-arm64.app.tar.gz`), or a local `pnpm --dir desktop tauri build --no-bundle`.
- **An agent client** for the steps that name a command: the one in `C4.1-attached-agent.md` (Python 3.11+, `mcp==2.0.0`; Preferences › Agent access: **agent.server.enabled** on). Commands are typed as `run_command {"id": "…", "params": {…}}`; `inspect_ui {"target": "window"}` reads the UI tree.
- **A machine or VM without a GPU** (a Windows VM on the Basic Render Driver, or macOS in a VM), with Python 3.11+, `mcp==2.0.0` and a checkout of the repository for step 3.

Needs a GPU-less machine or VM (for example a Windows VM with the Basic Render Driver, or macOS in a VM).

1. Start Toontown with `--canvas-metrics`; File › New, Drawing workspace. `inspect_ui` the `drawingView.canvas` node →
   its value names the back end (`webgl2`; WebGPU has no adapter here) and no `lastError`.
2. Draw strokes, paint, pan and zoom → everything shows and responds.
3. Run `scripts/c42-canvas-measure.py <toontown binary> <out> --bounds ci` on the machine and attach
   `measurements.json`: the frame time and release-to-committed numbers decide E-C3 (≥ 30 fps on the rule-set
   scenes keeps the webview's software path; otherwise tiled host bitmaps are compared).
