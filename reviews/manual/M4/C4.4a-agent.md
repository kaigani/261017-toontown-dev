# C4.4a — Agent surfaces with a real agent (≈ 12 min)

Spec: 01 §7.3 (Agent access), 11 §6.4 (the indicator), §11 (activity), §15.1; `reviews/M4-design-agent-surfaces.md`
§2-§6; SI-173 to SI-179. The D-39 and D-44 tables and `scripts/c44a-e2e.py` check each control's command, the token
regeneration and the server switched off and on; this script checks the wording, the layout and the feel with a real
agent. The agent script is the one of `C4.1-attached-agent.md` (its prerequisites and `agent.py`).

1. Preferences › Agent access: check **Run the agent server**, OK. The status line at the top of the category says the
   server is running at the endpoint, with 0 sessions. **Allow remote connections** is disabled and says why.
2. Connect `agent.py` with the discovery file. The status line (reopen Preferences) says 1 session; the status bar's
   agent indicator shows the client.
3. From the agent: `run_command {"id": "project.create", "params": {"name": "Agent surfaces"}}`, then three edits (for
   example `draw.rectangle.add`). Open the indicator's popover → **Activity…** opens the Activity panel; the entries
   appear as the agent works, newest first, with the command's label, the status, the changed count and the time.
4. Draw one stroke yourself. Select the agent's first entry → **Undo back to before this entry** asks "Undo n steps,
   1 of them yours?"; Cancel leaves everything; Undo moves the history back (the History panel shows it).
5. Select any entry → **Copy as batch JSON**, paste into a text editor → `{"label": "Agent activity", "atomic": false,
   "stopOnError": true, "steps": [...]}` with the entry's command.
6. **Export…** → choose a file → the file holds one JSON line per entry.
7. In the sessions strip: change the policy to Observe → the agent's next edit is refused with a scope error. Scopes…:
   tick ui, OK. **Pause** → the agent's next call waits; **Resume** → it goes on. **Disconnect** → the agent's
   connection ends and the strip is empty.
8. Preferences › Agent access: **Regenerate token…** asks first, with Cancel as the default (Return cancels). Choose
   Regenerate → a connected agent is disconnected; the discovery file has the same endpoint and a new token; `agent.py`
   reconnects with it.
9. Change Jobs at once to 3 and tick two namespaces under **Expose commands as individual tools**, OK → a newly
   connected agent lists the typed tools of those namespaces. Quit and start Toontown again → Preferences shows both
   settings as you left them; **Keep the activity log beside the project** too.
10. **macOS:** the same steps; the menus and popovers follow the platform's look; Return and Esc act as on Windows.
