# C4.1 — Themes follow the system (≈ 3 min)

Spec: 01 §5.8.

1. Preferences › Interface › Theme = **Follow system** (default). Switch the OS between light and dark appearance →
   Toontown switches at once, no restart.
2. Choose **Dark**, then **Cancel** in Preferences → the preview reverts to the previous theme.
3. Choose **Light**, **OK**, restart → still light.
4. Save the file below as `<settings>/Themes/night-blue.json` (`<settings>` is `%APPDATA%\Toontown\Settings` or
   `~/Library/Application Support/Toontown/Settings`; create `Themes`), restart → Preferences › Interface › Theme lists
   **Night blue**; choose it, **OK** → the window turns blue-grey. Change `"formatVersion"` to `"9.0"`, restart → the
   theme is no longer offered (an invalid file is ignored) and the window falls back to Follow system.

   ```json
   {
     "format": "toontown-theme",
     "formatVersion": "1.0",
     "themeId": "night-blue",
     "name": "Night blue",
     "dark": true,
     "colours": {
       "background": "#141A24FF",
       "surface": "#1C2533FF",
       "surfaceAlt": "#243042FF",
       "border": "#34445CFF",
       "text": "#E3E9F2FF",
       "textMuted": "#9AA8BCFF",
       "accent": "#4C8DFFFF",
       "accentText": "#FFFFFFFF",
       "selection": "#2D5BA8FF",
       "focus": "#7FB0FFFF",
       "danger": "#FF5D5DFF",
       "warning": "#FFB547FF",
       "success": "#4CC38AFF",
       "tooltipBackground": "#0B1018FF",
       "tooltipText": "#E3E9F2FF",
       "tabActive": "#2A3850FF",
       "tabInactive": "#1C2533FF"
     }
   }
   ```
