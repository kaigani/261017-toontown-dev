# C4.1 — Themes follow the system (≈ 3 min)

Spec: 01 §5.8.

1. Preferences › Interface › Theme = **Follow system** (default). Switch the OS between light and dark appearance →
   Toontown switches at once, no restart.
2. Choose **Dark**, then **Cancel** in Preferences → the preview reverts to the previous theme.
3. Choose **Light**, **OK**, restart → still light.
4. Optional: copy a theme file into `<settings>/Themes/` (format in ADR-0021 decision 11), restart → it is listed and
   selectable; an invalid file is ignored.
