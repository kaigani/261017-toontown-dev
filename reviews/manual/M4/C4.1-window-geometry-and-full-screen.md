# C4.1 — Window geometry, full screen, multiple monitors (≈ 6 min)

Spec: 01 §5.4 (visibility guarantee), §5.6, §11 (window geometry persisted).

1. Move and resize the main window; quit; start again → same position and size.
2. With two monitors: move the window to the second monitor, quit, disconnect that monitor, start → the window is on
   the remaining monitor, fully reachable.
3. View › Full Screen (F11 / ⌃⌘F) → full screen with the workspace's full-screen arrangement; again → back to the
   normal arrangement.
4. macOS only: Window › Minimise (⌘M) minimises; Window › Bring All to Front restores.
