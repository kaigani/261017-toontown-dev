# C4.1 — Display scaling at 150 % and 200 % (≈ 6 min)

Spec: 01 §5 (window), §11 (window geometry restored). Found uncovered in round 1 (C41-R1-22).

1. Set the display scaling to **150 %** (Windows: Settings › System › Display › Scale; macOS: Displays › a "Looks like"
   resolution of about two thirds of the native width). Start Toontown.
2. Text, toolbar buttons, the tool rail, tabs and the status bar are sharp (not blurred) and nothing is clipped.
3. Resize the window to about half the screen and move it; quit (File › Quit); start again → it opens at the same place
   and size.
4. Window › Panels › History, then float it (double-click its tab) → its window is sharp; move it; quit and start →
   it comes back at the same place.
5. Repeat steps 1-4 at **200 %**.
6. With two monitors of different scaling, drag the main window from one to the other → it re-renders sharp on the
   second one, and its size in logical pixels stays the same.
