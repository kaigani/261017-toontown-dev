# C4.1 — Windows menu and shortcuts (≈ 5 min)

Spec: 01 §5.1, §8.2, §8.4; ADR-0021 decision 9 (on Windows the shortcut is shown in the menu label and the window's
key dispatch runs it).

1. Start Toontown. Menus: File, Edit, View, Window, Help. File ends with Preferences… and Quit.
2. The menu labels show shortcuts on the right (Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+W, Ctrl+Q, Ctrl+Z …).
3. Create a project from the start screen (Enter in the Name field). Window › Panels › **History** (it shows "Initial
   state"). **File › Project Properties…**, change **Frame rate** from 24 to **12**, **OK** → History lists one new
   step, "Project Properties". **Ctrl+Z** → exactly one step is undone: History's current entry is "Initial state"
   again and Project Properties shows 24. **Ctrl+Y** → 12 again; **Ctrl+Z**, then **Ctrl+Shift+Z** → 12 again (each
   redoes one step).
4. **F11** toggles full screen; **F1** opens the help viewer.
5. Click into the start screen's Name field (Help › Start Screen) and press **Delete** and **A**: they edit the text and
   run no command; **Ctrl+S** still saves.
6. **Ctrl+Q** → Save / Don't Save / Cancel; **Don't Save** quits.
