# C4.1 — Floating panels as windows, across monitors (≈ 8 min)

Spec: 01 §5.4 (floated as a separate window; floating panels remember their size and position; Close active panel;
Toggle floating windows), 01 §5.5, §11. Design: reviews/M4-design-floating-windows.md (ruling O-2).

1. Open a project. Window › Panels › **History**. Double-click its tab → it becomes a window of its own, titled
   History, with no menu bar.
2. Move it and resize it. Quit (File › Quit, Don't Save) and start again, open the project → History is a window again
   at the same place and size.
3. Double-click the History window's title strip → it docks back into the main window; its window closes.
4. Float it again; drag it onto a second monitor; quit and start → it comes back on that monitor. Disconnect the second
   monitor and start → it appears on the remaining monitor, fully reachable.
5. In the main window, **File › Project Properties…**, change **Frame rate** to **12**, **OK** → the floating History
   window lists the new step "Project Properties". Click into the floating History window, then press **Ctrl+Z**
   (**⌘Z**) → that step is undone (History's current entry moves back one, Project Properties shows the previous frame
   rate): the shortcut works from a float.
6. Close the float with its window's close button → the panel is hidden (Window › Panels › History has no check mark);
   choose it again → it shows again as a float where it was.
7. Minimise the main window → the float hides; restore → it shows again. Window › Raise All → both come to the front.
8. Float **Drawing view** (Window › Views): its window becomes the active view (the status bar mode says Drawing) when
   it has the focus.
