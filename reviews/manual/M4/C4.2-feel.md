# C4.2 — Drawing feel on a large drawing (≈ 8 min)

Spec: plan §6 (input-to-ink ≤ 1 frame, release-to-committed ≤ 150 ms on a large drawing); ADR-0007.

**Prerequisites** (everything this script assumes; nothing else is needed):

- **A build of the handoff head:** the CI artifact `desktop-Windows` or `desktop-macOS` of the run named in `reviews/M4-C4.2b-handoff.md` §1 (Windows: `default-build/toontown.exe`; macOS: unpack `Toontown-macos-arm64.app.tar.gz`), or a local `pnpm --dir desktop tauri build --no-bundle`.
- **An agent client** for the steps that name a command: the one in `C4.1-attached-agent.md` (Python 3.11+, `mcp==2.0.0`; Preferences › Agent access: **agent.server.enabled** on). Commands are typed as `run_command {"id": "…", "params": {…}}`; `inspect_ui {"target": "window"}` reads the UI tree.
- **Choosing a tool:** the window has no tool buttons yet (they arrive with their owners). Choose a tool through the agent client, `run_command {"id": "tool.active.set", "params": {"toolId": "brush"}}` (ids: `select`, `brush`, `pencil`, `rectangle`, `ellipse`, `polyline`, `line`, `eraser`, `cutter`, `scissor`, `paint`, `zoom`, `grabber`), or bind a key once: `run_command {"id": "keymap.set", "params": {"commandId": "tool.active.set", "params": {"toolId": "brush"}, "keys": "F8"}}`.
- **The large drawing:** `python scripts/c42-canvas-measure.py <toontown binary> <out folder> --bounds workstation` builds the 50,000-point drawing in its own private user folder and measures it (Python 3.11+, `mcp==2.0.0`, a checkout of the repository); for the by-eye steps, draw on a drawing you made dense with the Brush for a few minutes instead.

1. Start Toontown with `--canvas-metrics` (Windows: `toontown.exe --canvas-metrics`; macOS:
   `Toontown.app/Contents/MacOS/toontown --canvas-metrics`). File › New, Drawing workspace.
2. Let an agent (or `scripts/c42-canvas-measure.py`) build the 50,000-point drawing, or draw for a few minutes until
   the drawing is dense.
3. Draw fast scribbles with the Brush → the ink follows the pen without visible lag or gaps (coalesced samples keep
   every sample); on release the stroke appears where the ink was, without a visible jump or flash.
4. Pan and zoom continuously while the drawing is dense → motion stays smooth.
5. Optional: `inspect_ui` the `drawingView.canvas` node: its value's `metrics` give the frame, input-to-ink and
   release-to-committed numbers measured on this machine; paste them below.
