# C4.2 — The canvas against the final render (≈ 10 min)

Spec: 02 §4.2, §10; 06 §6.9, §6.10; ADR-0006, ADR-0007.

**Prerequisites** (everything this script assumes; nothing else is needed):

- **A build of the handoff head:** the CI artifact `desktop-Windows` or `desktop-macOS` of the run named in `reviews/M4-C4.2b-handoff.md` §1 (Windows: `default-build/toontown.exe`; macOS: unpack `Toontown-macos-arm64.app.tar.gz`), or a local `pnpm --dir desktop tauri build --no-bundle`.
- **An agent client** for the steps that name a command: the one in `C4.1-attached-agent.md` (Python 3.11+, `mcp==2.0.0`; Preferences › Agent access: **agent.server.enabled** on). Commands are typed as `run_command {"id": "…", "params": {…}}`; `inspect_ui {"target": "window"}` reads the UI tree.
- **Choosing a tool:** the window has no tool buttons yet (they arrive with their owners). Choose a tool through the agent client, `run_command {"id": "tool.active.set", "params": {"toolId": "brush"}}` (ids: `select`, `brush`, `pencil`, `rectangle`, `ellipse`, `polyline`, `line`, `eraser`, `cutter`, `scissor`, `paint`, `zoom`, `grabber`), or bind a key once: `run_command {"id": "keymap.set", "params": {"commandId": "tool.active.set", "params": {"toolId": "brush"}, "keys": "F8"}}`.
- **A colour:** the window has no colour panel yet. A new project's first palette has the default swatches; make one current through the agent client by its position, `run_command {"id": "colour.current.set", "params": {"colourId": "palette:#1/swatch:#2"}}` (swatch 1, 2, 3, ... of palette 1; common addressing).
- **A gradient swatch** is optional: palettes cannot be edited in the window yet, so skip the gradient comparison unless the project already has one.

The interactive canvas is a preview (06 §6.10): exported pixels come only from the final renderer. This script compares
the two by eye at several zooms.

1. File › New, Drawing workspace. Draw brush strokes of several widths, a pencil line with corners (Polyline), a
   rectangle and an ellipse; paint the rectangle and the ellipse with different colours, and one zone with a gradient
   swatch if the palette has one.
2. Render › Render Frame (or `render.frame.run` through an agent) at the view's size and open the PNG beside the window.
3. At 100 % compare: stroke widths, caps and joins (round), fills (no gaps between fill and line), gradient direction.
4. Zoom to 400 % and 1600 % (wheel or the Zoom tool) → curves stay smooth (no visible facets; the canvas reloads at a
   finer bucket, SI-137); zoom to 25 % → thin lines stay visible.
5. Onion skin on (previous 2, next 1) with three drawings exposed → the previous ones are red, the next green, the
   farther fainter (50/30/15 %); Outline only → only brush outlines and centre lines.
6. Auto light table on with a second element → its drawing appears washed out behind; a static light-table entry
   (Exposure Sheet cell › send to static light table) appears washed out, over or under as placed.
7. Grid on: Normal at 100 % (minor lines) and 25 % (major only); 12 Field and 16 Field (nested rectangles, cross-hair);
   Overlay on → the grid is drawn over the painted rectangle.
