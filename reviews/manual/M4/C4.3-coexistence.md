# C4.3 — A real agent while you drag (≈ 6 min)

Spec: 11 §6.4 lines 236-238 (user priority), lines 586-587 (E6); 01 §12.1 rule 8; busy note §5; SI-157.

**Prerequisites** (everything this script assumes; nothing else is needed):

- **A build of the handoff head:** the CI artifact `desktop-Windows` or `desktop-macOS` of the run named in
  `reviews/M4-C4.3b-handoff.md` §1, or a local `pnpm --dir desktop tauri build --no-bundle`.
- **The fixture project** `reviews/manual/M4/fixtures/c43-camera.animpkg`, copied somewhere writable, opened with
  File › Open….
- **An agent client**: the one in `C4.1-attached-agent.md` (Python 3.11+, `mcp==2.0.0`; Preferences › Agent access:
  **agent.server.enabled** on). A second person typing the agent's commands helps; alone, type the command first and
  press Enter while you hold the drag with the other hand.

1. Choose the Transform scene tool: `run_command {"id": "anim.tool.set", "params": {"tool": "transform"}}`. Select Bob
   (click him).
2. Press on Bob (away from his pivot) and hold. While holding, send:
   `run_command {"id": "anim.transform.set", "params": {"nodeIds": ["el_01K7JJN800FWYC1TEZ57XR65SW"], "target": "static", "position": {"x": 0.5, "y": 0}}}`
   → the agent's command does not answer while you hold; `get_state` (or `app.state.get`) from a second client shows
   `modal: {kind: "gesture", title: "transform"}`.
3. Let go within ten seconds → your drag is committed first, then the agent's command answers `ok`; Edit › Undo's list
   shows your "Move Element" and then the agent's step, labelled with the agent's name.
4. Drag Bob again (your later step). Then have the agent send
   `run_command {"id": "edit.undo", "params": {"ifTop": "<the agent's step id from step 3's answer>"}}` → it answers
   `undo.notTop`, naming your step; nothing is undone.
5. Press on Bob and hold for more than ten seconds while the agent sends the command of step 2 → after ten seconds it
   answers `ui.busy` (blocked by your gesture) while you still hold; when you let go, your drag is committed.
6. The agent indicator in the status bar names the agent while it is connected; Activity… lists the agent's command and
   the refused undo.
