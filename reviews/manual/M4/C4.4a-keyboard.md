# C4.4a — Keyboard-only use of the new panels, sheets and menus (≈ 10 min)

Spec: 01 §8 (keyboard), §5.3-§5.4 (context menus, the dock tab's checklist), §5.7 (toolbar customisation); 02 §6.1
(Pen panel), §7.6.1 (Text panel), §9 (drawing inspector); D-40 ("keyboard-only operation of each new panel");
`reviews/M4-design-panels.md` §1, §9. The D-39 table checks each control's command with real clicks; this script
checks what only a person can judge: that everything is reachable without the pointer and that the focus is always
visible.

Do not touch the mouse or trackpad after step 1.

1. Start Toontown, click once in the start screen, create a project named `Keys` with the keyboard (Tab to Name,
   type, Return).
2. **Pen panel.** Window › Panels › Pen (Alt then the arrow keys on Windows; on macOS ⌃F2 then the arrows). Tab into
   the pen list → the current pen shows a focus ring; Tab moves from pen to pen and Space or Return chooses one (the
   current pen changes). Tab to the Maximum size slider: the arrow keys change it one step per press, and the value is applied
   when the key is released (one undo step per press). Tab reaches New, Delete, the tip shape list and Advanced; Space
   on Advanced opens it.
3. **Properties panel, Tool options.** Window › Panels › Properties. Tab reaches the page tabs (Tool options, Pen,
   Drawing); Space or Return switches pages. On Tool options: Draw on Top Layer, Draw Behind and Snap to Contour toggle
   with Space; a list (the thickness, the gap closing of a paint tool) opens with Alt+Down and chooses with Return.
4. **Drawing page.** Tab to the name field, type a new name, Return → the drawing is renamed (Edit › Undo shows
   "Undo Rename Drawing"); Esc while typing restores the old name. Show preview toggles with Space.
5. **Text panel.** Window › Panels › Text. Every field (font, size, Bold, Italic, alignment, baseline, kerning) is
   reachable with Tab and changes with the keyboard.
6. **Customize Toolbar.** Window › Customize Toolbar…. Tab into the toolbar's items; Space selects one; Alt+Up and
   Alt+Down move it; Delete removes it; Tab to Available items, type in the filter, choose an item, Add. Return
   applies (the toolbar changes); open it again and Esc → nothing changes.
7. **Context menus.** Focus the Drawing view (Tab until its canvas has the ring), press the context-menu key or
   Shift+F10 → the Drawing menu opens at the view's corner with its first item focused. Down, Up, Home and End move;
   the headings Arrange and Transform are skipped; Return on Flip Horizontal flips the selection. Esc closes a menu and
   the focus is back on the canvas. Tab to a dock tab and do the same → the panel checklist, with its check marks.
8. **Camera list.** Tab to the main toolbar's camera list; Alt+Down opens it; choose another camera with the arrows and
   Return → the Camera view frames through it.
9. **Load report.** Save a project in folder form (File › Save As…, a name ending in `/`), close it, set
   `"formatVersion": "1.3"` in its `manifest.json`, and open it → the load report window appears without taking the
   focus away from the work; Tab reaches its groups (Space opens one), Copy details and Close; Esc closes it.

## macOS: the webview's own menu and keys (ruling D-70 item 2, D-72 item 3)

On macOS the page's rule alone governs the menu (`useNoBrowserMenus`): there is no host filter. With the application
open (a project, Preferences › Agent access shown for the last two checks):

1. **No Reload.** Secondary-click (Control-click) a main toolbar button, a Pen panel row, the Drawing view's empty canvas
   area and a text field (the Text panel's Font field): no menu shows "Reload". ⌘R and ⌘⇧R reload nothing (a drawn
   stroke is still there, the panels are where they were).
2. **No Back.** None of those menus shows "Back"; ⌘[ and ⌘← (outside a text field) navigate nothing.
3. **No Forward.** None shows "Forward"; ⌘] navigates nothing.
4. **No Inspect Element.** None shows "Inspect Element".
5. **No link or download entry.** None shows "Open Link", "Open Link in New Window", "Download Linked File", "Copy
   Link" or any other link or download entry (the page has no links; a text field's menu has none either).

What the system adds to a text field's menu for text is allowed (Look Up, spelling and grammar, substitutions,
transformations, speech, services, search).
