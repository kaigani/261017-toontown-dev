# C4.4b — Text tool with an input method, dead keys and composition (≈ 12 min)

Spec: 02 §7.6 lines 664-681 (the Text tool), 01 §8.4 lines 860-866 (keys in text entry); design note 5 §4 (input
methods), SI-193. A person's check: CI cannot drive a system input method.

Prepare: a project open, the Drawing view shown, the Text tool chosen (T), the Text panel visible.

## Windows (Microsoft IME, Japanese and Chinese Pinyin)

1. Click on empty canvas → a text box appears with a caret; the Text panel's heading reads "Next typed text".
2. Switch the input method to Japanese (Win+Space). Type `nihongo` → the pre-edit appears at the caret, underlined, at
   the run's size; the candidate window opens next to it; nothing is laid out in the drawing yet.
3. Press **Space** to convert, **Return** to commit → the text `日本語` appears laid out once; Edit › Undo shows one
   "Typing" step for it (with the earlier keystrokes of the run, if any).
4. Switch to Chinese Pinyin. Type `zhongwen`, choose a candidate with a digit key → the characters are committed once.
5. **Esc** during a composition cancels the pre-edit only (the session stays open; the caret stays, steady).
6. Switch to English (United States-International): type **'** then **e** → `é` once (a dead key); **'** then
   **Space** → `'`.
7. **Ctrl+Z** → the whole run of typing is undone in one step; **Ctrl+Shift+Z** (or Ctrl+Y) redoes it.
8. Select two characters with **Shift+Left** twice, then click Bold in the Text panel → only those two characters turn
   bold; the heading reads "Selected text"; Undo shows "Text Property Modified".

## macOS (Japanese – Romaji, Pinyin – Simplified)

Repeat steps 1-8 with the macOS input sources (switch with Ctrl+Space; dead key: **Option+E** then **E** → `é`; undo
**⌘Z**, redo **⇧⌘Z**).
