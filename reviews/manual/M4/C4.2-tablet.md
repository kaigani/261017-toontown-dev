# C4.2 — A physical pen in the Drawing view (≈ 15 min)

Spec: 02 §6.3, §13.3; ADR-0009 lines 70-72 (one input abstraction), 165-166, 214-220; ruling D-9.

Needs a pen tablet (or a pen display) on Windows and on macOS. The canvas reads the pen through the webview's pointer
events (the one input abstraction); native tablet sources wait for this evidence. With `--canvas-metrics` the canvas
publishes its timings; the steps below record what ADR-0009 asks before any native source is built.

1. Start Toontown, File › New, Window › Workspaces › Drawing; pick the Brush tool and a dark colour.
2. **Pressure.** Draw five strokes, each from very light to firm pressure → the committed strokes thin to thick
   (the Brush's pressure response). Note any stroke whose start or end is missing (the **prefix/tail completeness**
   ADR-0009 asks about: the first and last samples of a native stream).
3. **Tilt.** Draw holding the pen upright, then tilted strongly → no stroke changes with tilt (SI-125: tilt is
   carried, read by no tool). Note whether the system reports tilt at all (it is recorded in the gesture).
4. **The eraser end.** Turn the pen over and drag across a stroke → the stroke is erased (a temporary Eraser, 02 §5.2);
   turn it back → the Brush draws again. Note the **per-device state**: does the tool come back after each flip?
5. **Lifecycle.** Hover the pen over the canvas without touching, leave the canvas, come back, put the pen down outside
   the canvas and drag in → no stroke starts outside the canvas or from hovering; a stroke started inside and dragged
   out ends where the pen lifts.
6. **Two devices.** With the pen and a mouse (or a second pen), draw with one while the other moves → strokes are not
   mixed between devices (**simultaneous-device segmentation**: one gesture at a time).
7. **Coordinates.** On a Retina / high-DPI display and, if available, a second display at another scale, draw a stroke
   along a ruler edge → the committed stroke lies exactly where the pen went (no offset, no scale error) on both.
8. Pen settings (02 §6.3): Preferences › Tablet, change the pressure curve → the next strokes respond accordingly.
