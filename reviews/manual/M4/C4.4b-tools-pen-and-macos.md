# C4.4b — The four drawing tools with a pen, and on macOS (≈ 15 min)

Spec: 02 §7.1.2 lines 445-463 (Contour Editor), §7.1.3 lines 465-473 (Perspective), §7.1.4 lines 475-481 (Reposition
All Drawings), §7.6 lines 664-681 (Text tool); design notes 3 (`reviews/M4-design-contour-editor.md`), 4
(`reviews/M4-design-envelope-tools.md`) and 5 (`reviews/M4-design-text-tool.md`); SI-184 to SI-196. A person's
check: CI and the workstation receipts drive a mouse through the operating system, not a pen, and run on Windows only.

Prepare: a project with one drawing element, a rectangle and an ellipse drawn on frame 1, the Drawing view and the
Camera view both shown, the Tool Properties panel visible.

## With a pen or tablet (Windows, and macOS if a tablet is at hand)

1. **Contour Editor** (choose it from the tools palette). Tap an anchor of the rectangle with the pen tip → it is
   selected (filled square); drag it → the outline follows the pen while it moves and lands where the tip is lifted;
   Edit › Undo shows one "Contour Editing" step.
2. Tap and drag a segment → it bends; the anchors at its ends stay put.
3. Hold the pen's side button (if it is mapped to the right button: nothing should happen; if mapped to Alt) and tap
   an anchor → its handles are reset (straight, SI-186).
4. Turn Snap to Contour on (Tool Properties). Drag an ellipse anchor to within a few pixels of the rectangle's edge →
   it lands on the edge; with Snap off it lands where the pen is lifted.
5. **Perspective.** Select the rectangle (Select tool), choose Perspective. Drag a corner handle with the pen → the
   ink is previewed bent while the pen moves; on lift the commit matches the preview (no jump). Drag a side handle
   with the pen and Shift held → the side spreads or closes symmetrically.
6. **Reposition All Drawings.** Drag inside the box → every drawing of the element moves; drag just outside a corner
   → rotation; one "Reposition All Drawings" undo step each.
7. **Text tool.** Tap empty canvas → a text box with a caret; type with the keyboard; tap inside the text with the pen
   → the caret moves there; drag across characters → they are selected (highlighted).
8. A pen with pressure: none of these tools reads pressure (the strokes keep their widths); confirm no width changes
   after steps 1-6.

## On macOS

Repeat steps 1-7 with the trackpad or mouse, then:

9. The alternate modifier is **Option**: Option-click an anchor in the Contour Editor → reset; Option-drag a
   Perspective side handle → the alternate side drag (SI-188); Option-drag a Reposition All corner → the alternate
   corner drag.
10. Temporary select is **⌘** in the Contour Editor: ⌘-drag on empty canvas selects anchors by rectangle.
11. In a Text tool session: ⌘A selects all the text, ⌘C / ⌘X / ⌘V copy, cut and paste within the box, ⌘Z undoes the
    typing run in one step and ⇧⌘Z redoes it; ⌥←/⌥→ move by word (01 §8.4).
12. The Text panel's heading reads "Next typed text" with a caret and "Selected text" with a selection; Bold applies
    to the selection only.
