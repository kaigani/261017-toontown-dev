# C5.1b — The Timeline from the keyboard (≈ 6 min)

Spec: 04 §16 (key bindings), 01 §8 (keyboard); plan §6.5. Automated: the arrow keys (Vitest), Show Timeline Selection's
key (`c51b_show_timeline_selection`), the dialogs (D-44).

Open the sample project. After step 1 do not touch the pointer.

1. Click once in the Timeline's tracks.
2. **Left / Right** arrows → the current cell moves a frame (the playhead follows); **Up / Down** → it moves a row.
3. **,** and **.** → previous / next frame; **Shift+,** / **Shift+.** → previous / next drawing.
4. **Alt+,** / **Alt+.** → previous / next element (the current row changes).
5. Scroll the Timeline so the current row is out of view, then press **/** (Show Timeline Selection) → the row comes
   back into view.
6. **Enter** plays, **Shift+Enter** stops.
7. **Shift+F10** on a focused row → the row's menu opens at the row; arrow keys move through it, **Enter** chooses,
   **Esc** closes it.
8. Element › Rename… from the keyboard (Alt, then the arrows) → type a name, **Enter** renames; reopen it, **Esc**
   cancels.
9. Double-click a row's name, type, **Enter** → renamed in place; in the field, **Ctrl+A** (macOS ⌘A) selects the
   field's text, not the rows.
