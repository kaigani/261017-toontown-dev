# C5.1b — The Timeline on macOS (≈ 6 min)

Spec: 04 §16 (modifier roles; SI-211: extend Shift, toggle ⌘, single cell Option, copy Option, link Option+⌘);
01 §5.3 (the native menu bar). Automated on CI: the three-way rows through the window's event path on macOS
(`timing gui (macos-latest)`), which use the same roles.

1. Open the sample project.
2. **Control-click** and **two-finger click** a row, a cell and the ruler → each opens the same menu a secondary click
   opens on Windows.
3. Click a row's name, then **⌘-click** another → both are selected; **⌘-click** again → the second is deselected.
   **Shift-click** a third → the rows between are selected.
4. Select two cells and drag them with **Option** held → copied; with **Option+⌘** → linked (the target shows the same
   drawings, a later edit of one shows in both).
5. The native menu bar: **Element** (Add, Arrange, Select, Visibility, Lock, the colour and note items) and **Play**
   (Play/Stop, Loop, Force Frame Rate, Playback Rate, Playback Range) → each item enabled as the Timeline says; Loop and
   Force Frame Rate show a check mark when on; the chosen rate and range mode show theirs.
