## Findings

### C32-R1-01 — P1 — Passage inversion misses the first subframe crossing

Clause: 05 §10.5 requires the smallest frame with V(f) >= the control-point arc length, including non-monotonic velocity, to 1e-4 frame, rounded to three decimals. The binding ruling confirms this interpretation.

Reproduce: `cargo test -p tt-anim --locked -j 4 --test c32_r1_passage --test c32_r1_corpus --no-fail-fast`.

A straight unit path has pins at frames 1 and 3. A frame-2 spline velocity key has value zero. The frame-1 right and frame-2 left handles are `(1/3,1)` and `(-1/3,1)`. The independent Bernstein polynomial on [1,2] is x(u)=1+u and V(u)=3u(1-u). For arc 1/2 the required first crossing is `1+(1-sqrt(1/3))/2`, reported **1.211**; observed **2.500**. Integer endpoint scanning misses an excursion entirely within one frame.

The seeded corpus (`C32019AB6701`) finds **3023/4096** misses; the exact-whole-frame control passes. The fixed case is the small regression; the seeded corpus supplements it. Evidence: `passage.txt`, `passage-corpus.txt`. Both finding targets retain their failing assertions.

Fix direction: split velocity segments at extrema and boundaries, bracket every possible crossing, then solve the earliest bracket within the charged convergence budget. Whole-frame scanning cannot establish the normative first crossing.

### C32-R1-03 — P2 — Rounded default FOV exceeds the exact-frame tolerance

Clauses: 05 §1.2, §1.3, §2.7 and §19.1.6; SI-102 records the conflicting table default rather than an external ruling waiving exactness.

Reproduce: `cargo test -p tt-anim --locked -j 4 --test c32_r1_default_frame`.

At camera Z=16, roll=0, FOV=41.1121, the table-plane width is **12.000003045341391** fields. Required: exactly 12 fields, with the numeric acceptance tolerance of 1e-6. The approximately 3.045e-6 width error exceeds that tolerance. The fixed assertion remains failing in `independent-maths.txt`. The stored value does match the camera/property tables; this finding concerns the incompatible exact-width requirement, not a claim that the default table is absent.

Fix direction: obtain an explicit reconciliation of the normative exact expression and rounded tables, then use one consistent default and regenerate affected schemas/examples. A builder-only note does not resolve both requirements.

### C32-R1-04 — P2 — RFC `test` distinguishes integer zero from floating zero

Clauses: 10 AG-02 / the RFC 6902 contract of `doc.object.patch`; [RFC 6902 §4.6](https://www.rfc-editor.org/rfc/rfc6902.html#section-4.6) requires numeric comparison of JSON numbers.

Reproduce: `python reviews/evidence/M3-C3.2-r1/sdk-matrix.py target/release/toontown-headless.exe "$env:TEMP/c32-r1-sdk-repro"`; inspect `C32-R1-04 RFC numeric equality` in `results.json`. The script exits 1 while its finding assertions fail.

After setting a peg's static skew to zero, `ops: [{op: "test", path: "/transform/skew", value: 0}]` returns **doc.patchTestFailed**. The otherwise identical request with `value: 0.0` succeeds. Required: both succeed without changing the document. This concerns common patch comparison exposed on the newly owned transform surface; introduction in this checkpoint is not established.

Fix direction: implement recursive RFC numeric equality without losing integer precision, including numbers nested in arrays/objects. Retain unlike-type refusals and transaction rollback. Evidence: `sdk-matrix.py`, `sdk-matrix/results.json`.

### C32-R1-05 — P2 — Mixed static/keyed event coalescing loses all-frame scope

Clause: 05 §19.4 requires the union of affected nodes, channels and frame range once per undo step.

Reproduce with the same SDK matrix command; inspect both `C32-R1-05 mixed event frame union` records. In one atomic batch, set static rotation to 13 and key skew 17 at frame 7. Repeat from the same base with the step order reversed.

Observed in both orders: exactly one `anim.changed`, containing both channels, but **frames {from: 7, to: 7}**. Required: the static change's all-frame scope survives the union; a single-frame range must not describe the complete affected range. Standalone static events omit `frames`; `coalesce_changed` adds/preserves a finite keyed range when merging them. Consumers using that range can retain stale evaluations elsewhere.

Fix direction: make all-frame invalidation absorbing in the union, preserve affected interpolation intervals for keyed edits, and retain transaction boundaries. The direct reviewer query test separately verifies one event per each of three transactions. Evidence: `sdk-matrix/results.json`, `independent-queries.txt`, `anim_camera::coalesce_changed` and `anim_common::emit_static`.

### C32-R1-06 — P2 — A finite world matrix reaches an internal encoding failure

Clauses: 05 §2.5 read-back; ADR-0019 output rule 5 requires a typed `anim.valueOutOfRange` refusal for non-finite results.

Reproduce: `python reviews/evidence/M3-C3.2-r1/finite-decomposition.py target/release/toontown-headless.exe "$env:TEMP/c32-r1-finite-repro"`. This fixed probe remains failing (exit 1).

Create 26 nested pegs, each with static X/Y scale 1,000,000 (the permitted per-node bound), then `anim.evaluate` the leaf at frame 1 with `include: ["world"]`. The matrix entries and analytic scale **1e156** are finite. Squaring the matrix coefficients in `decompose` overflows; observed response is **internal**, with `result encoding failed: arg.invalid: NaN and infinities are not valid JSON numbers`. Required: accurate finite read-back, or the declared typed numeric refusal before result encoding. The serializer prevents null output, but the evaluator misses the required error classification. Twenty-five such ancestors do not overflow the squared norm; 26 is the small fixed boundary for this chosen scale.

Fix direction: use a deterministic scaled norm built from the permitted arithmetic, and check decomposition outputs before serialization. Preserve the pinned numeric order and return `anim.valueOutOfRange` when the result cannot be represented. Evidence: `finite-decomposition.py`, `finite-decomposition/result.json`, `finite-decomposition-exit.txt`.

## Residual risks

Acceptance remains blocked by the active findings. Seeded coverage is finite: the passage corpus fixes horizontal handles to linear time; the new TCB corpus uses dyadic parameters; the reviewer camera corpus uses quarter-turn rolls. The supporting builder suites broaden those domains but do not constitute a second reviewer-authored 4096-case oracle for each domain. Arbitrary hierarchical conditioning, generic RFC numeric equality at large magnitudes and complete event invalidation intervals deserve targeted regressions after fixes. The new SDK checks do not independently repeat every kernel/UI scheduling interleaving. The local variant's second camera does not establish cross-OS variant bytes. Timing measurements establish observations on shared runners, not watchdog bounds for all accepted documents.

D-5 migration, bone kinematics, effect-channel execution, native bitmap mapping and view/render integration retain the named downstream owners. This review does not freeze their IPC or infer render acceptance from numeric evaluation. No product/spec file was edited; no inherited reviewer test or golden was weakened or skipped.

Previously registered C22-T2 and R1-12 remain with M11; this review does not close them.
