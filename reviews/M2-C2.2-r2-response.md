### Found while fixing R2-02/03 (fixed)

`doc.import.json` refused every bundle exported from a project whose document revision is ahead of the target's
("rev 2 is newer than documentRev 1"). Imported objects carried the source project's revisions into the staged
document. It shows as soon as the source project has been saved once, and is a C1.3 import bug that the new
import-path tests exposed. The import now resets the revisions of the bundle's objects before staging; they are
stamped with the import's revision when it commits (REV-01). Covered by the on-load/on-import recovery test, which
exports from a saved project.
