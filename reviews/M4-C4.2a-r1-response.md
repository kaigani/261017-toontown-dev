## 2. Observations

- **Light-table events** (part B): `set` and `remove` announce `drawAid.changed` only for an effective change. So do
  `view.active.set` (`shell.view`) and `tool.pen.rename` with an unchanged name (no step, no event); every other new
  event already followed the rule (`4d1bc17`).
- **Screenshot regions** (part A): a region is a rectangle of the view's pixel plane and is not clipped to the window;
  outside the window it shows what the canvas would show there (note 5 §1b). The 8 MB byte cap is checked after
  encoding, the only point at which it can be known, which ADR-0020 decision 8 permits (note 5 §1b).

## 3. Ruling D-13: the long-stroke split

Workstation, debug build, best of three, 10,000 samples (`budgets::long_stroke_split`, an ignored receipt):

| Path | Time |
|---|---|
| `pointer` Brush call (grouping, the press mapping, building `draw.stroke.add` with 10,000 points, the command) | 107 ms |
| direct `draw.stroke.add` with the same parameters, `fit: true` | 58 ms |
| the same as a dry run (handler and fitting, no commit) | 60 ms |
| direct, `fit: false` (more points reach the planar map) | 134 ms |
| `pointer` Grabber drag of 10,000 samples (grouping and mapping; trivial command) | 35 ms |

So of 107 ms: about **58 ms is the command itself** (fitting and the planar work, the bulk; the commit and the
integrity gate are within measurement noise, since the dry run costs the same); about **35 ms is grouping and
mapping** the samples; the remaining ~14 ms is handing 10,000 points through the command's JSON parameters. (The
reviewer's 250 ms is the same path on a slower machine.)

**(c)** Mapping the samples before the document thread is taken would save the ~35 ms, about a third of the hold. It
needs the view mapping at the press, which is session state and can change between a snapshot and the request. P1's
atomicity survives if the request checks that the view's transform is unchanged (compare the snapshot's matrix) and
remaps inside when it is not. The JSON hand-over (~14 ms) could be saved by passing the samples typed into the handler.
Neither is done in this checkpoint.

**(d)** Release-to-committed for a long stroke is a C4.2b budget case (plan §6, 150 ms large).
**(e)** Deferral recorded (handoff r2): the cost of very long strokes, owner M11 C11.1.
