| C22-R1-01 P1 near-anchor junction not shared | **fixed** (`8f92663`, `a1efc20`) | `planar/node.rs` (SI-067). Crossings and T-junctions are first collected as records. A record within 1/32 du of a junction's first record belongs to that junction; there is no chaining. Each junction gets one coordinate: the nearest existing anchor of an unchanged pencil or invisible participant (then lowest stroke and parameter), else the first record's point. Every participant meets it exactly, so the unchanged anchor is authoritative and the changed geometry is moved onto it. Other noding rules: a cut is merged into another only when both are the same junction and the path between them stays near it (a loop through its own junction is still cut twice); a cut at an open path's end becomes that end's junction (no zero-length pieces); an open end is a junction with every equally near stroke. | `c22_r1_geometry::a_crossing_near_an_existing_anchor_has_one_shared_junction`; `node.rs` tests `three_lines_crossing_near_one_point_share_one_junction`, `an_unchanged_anchor_near_a_crossing_is_the_junction_for_every_stroke`, `a_line_looping_through_its_own_crossing_is_cut_on_both_passes`, `a_line_through_the_meeting_point_of_two_pieces_is_split_there` |
| C22-R1-02 P1 overlap inheritance omits intersecting zones | **fixed** (`8f92663`) | `planar/fill.rs` `carry`. A grid index of old zone boxes yields every old zone whose box overlaps the new zone's with positive area. Each candidate is scored by exact grid polygon intersection: largest wins, ties go to the lower old zone ID. An old zone with a new zone's ID has the same polygon (R1-03), so it keeps its fill without an overlay and is not a candidate for any other zone. | `c22_r1_geometry::overlapping_zones_carry_fill_even_when_neither_interior_point_is_in_the_other`; `fill.rs` test `the_largest_overlap_wins_even_when_no_interior_point_lies_in_the_other_zone` (largest and tie) |

A vertex where the boundary goes straight on along the same strokes is left out, so a stroke ending on the edge from outside changes nothing. The cycle starts at its smallest token sequence, and hole cycles follow sorted. The ID is SHA-256 of that text. Carry-over scores by overlap (R1-02). | `c22_r1_geometry::changing_a_boundarys_geometry_changes_its_zone_id`; `c22_planar.rs::zone_ids_follow_the_boundary_only_and_are_reproducible` (reshape and one grid step change the ID; a far stroke and a spur do not); `c22_planar.rs::zone_ids_do_not_depend_on_where_tracing_starts_or_on_stroke_order`; `c22_determinism` golden (re-recorded, declared); the history oracles compute every zone ID independently |
