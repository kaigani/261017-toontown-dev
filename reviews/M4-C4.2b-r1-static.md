## Item 1: format

Rust module layout (crates/render/src/canvas.rs:14-44) and TypeScript format.ts:9-263 agree on little endian, 80-byte header, four-byte section alignment, major 1. Header offsets: magic 0, major 4, minor 6, length 8, bucket i16 10, slots u32 12, generation u64 16, revision u64 24, ULID 32..58, flags u16 58, records u32 60, bounds four f32 64..80. Slots: id length u16, kind u8, reserved u8, RGBA8, padded id. Records: kind u16, flags u16, whole length u32. Solid: two u32 counts, 12-byte vertices, u32 indices. Gradient: kind/stop count u8, reserved u16, six f32 matrix, stops (f32/RGBA8), mesh. Bitmap: dimensions u16, eight f32 corners, id length/slot u16, padded id, reserved u32. Both implementations skip reserved data. No extra JSON encoder replaces the binary encoder.

V1 magic format.ts:152; V2 major :157; V3 header :155-163; V4 count/length :210; V5 bounds and total :106,194,252; V6 index :227; V7 slot :181; V8 kind :243; V9 finite :131; V10 ULID :171. Builder format.test.ts checks corrupt.json cells and valid base; Rust tests/c42_canvas.rs checks same corpus. Reviewer suite mutates valid bytes, checks every truncated prefix, count multiplication beyond 32 bits, length overrun, kinds, magic, versions, coordinate NaN/infinity, index and slot. Typed refusals pass. Newer minor is accepted with unchanged layout; only major refusal is required, so this is an observation, not a defect.

### C42B-R1-21 (P2): restart retains old agent gestures

Clause: reviews/M4-C4.2-plan.md:270-272 D-7b requires old-generation gesture in progress discarded, never applied. CanvasView.tsx:151 cancelGesture clears only collector and overlay; event handler :330 invokes it on a differing generation, leaving playing and agentQueue untouched. playAgent later sends gestureCommit; agent-input has no generation, and attached.rs Pending has no generation. WindowIo finish runs the request against host.exec(), the current executor.

Reproduction: queue a long agent gesture, restart before playback completes, allow subsequent frames. Old samples continue in playAgent and can be submitted to the restarted executor; queued input can similarly start after restart. User-visible consequence: a gesture from the discarded engine can mutate the recovered document. The collector-only cancellation also cannot abort an agent gesture. Permanent source regression guard: python tests/adversarial/c42b-r1s-generation.py; fails at a1500000. It checks the specific missing queue invalidation, not a substitute for a future attached integration test. Fix direction: tag routing with generation and invalidate/abort queued and playing input on generation change at both host and window; ensure engine generation adoption cancels user collector even if already adopted before its first event. Verdict: FAIL.
