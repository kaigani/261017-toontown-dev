## 1. Built in round 1

- **Wire and dialogs (C41-R1-01, O-9).** A closed dialog reaches the kernel as `modal: null`; dialogs take the keyboard
  focus when they open; each window's sensor facts are its own and end with the window.
- **Attached mode (C41-R1-02, -03, -05, -06, -07; O-6, O-7, O-8).** Loopback binds only (typed error); a strict request
  parser; every security check before any body byte; bounded heads, bodies, connections, unauthenticated connections
  and SSE backlogs; a lingering close; authority parsers for `Host` and `Origin`; credentials from the OS random source
  only; idle session expiry (30 min); the discovery file never advertises a dead endpoint; request tokens owned per
  invocation and per window.
- **Settings (C41-R1-04, -08, -09; O-12, O-13).** The documents' version policy; whole-file shapes; honest set-aside with
  create-new copies; temporary-file clean-up under a folder lock; failed writes told once per file (`prefs.saveFailed`,
  SI-119).
- **Preferences and keymap (C41-R1-10 to -13).** Change events list effective changes only; one agent-policy validator;
  typed import errors; schema minima that pre-empted domain errors removed (audit in the response).
- **Freshness and restart (C41-R1-14, -15; O-14).** The tree and its sequence are one value; recovery release names and
  fences the abandoned engine; a restart is a generation change (serialised, requests answered from their generation,
  per-generation events and reports, fixed watchdog cadence, late replies clear, the autosave time in the
  confirmation; SI-120).
- **One availability source (O-10, C41-R1-20).** Kernel availability read by the native menu, the toolbar, the key
  dispatch and the MCP `key` tool.
- **Messages (O-11, C41-R1-21).** Help for every message id, checked mechanically in `check`.
- **Floating windows (O-2).** One OS window per float, reconciled by the host from the kernel; combined reports and one
  `inspect_ui` tree; per-window cancellation; restore at start; `workspace.changed` now announces any arrangement change.
- **Splitter drags (O-3, O-3a, SI-118).** A panel tabbed with itself is the same-place `window.panel.move`: it sets its
  area's size and changes nothing else; the splitter-drag end uses it in every area of every workspace.
- **CI (O-4).** A `lint` job; limits at least 1.3x the cold durations; shared release caches; no cache for three short
  jobs; one all-cold run measured (§7).
- **Also found and fixed in this round:** the C4.1 shell rewrite had dropped the `--ipc-bench` start-up hook; the
  Format list overflowed its card at narrow window widths; the GUI e2e's window capture and size helpers picked the
  process's "main window", which can be a float.
