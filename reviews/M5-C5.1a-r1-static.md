## Findings

### C51A-R1S-01 (P2): navigation that keeps the frame does not stop playback

Citation: spec/09_playback_export.md:138, navigation stops playback first.
Path: commands/timeline.rs:361-387 marks navigation and writes the frame;
commands/playback.rs:286-291 stops only if frame_changed (or scene changed).
Input: loop playback in a 1..60 range, current frame 1, invoke
 timeline.currentFrame.move {direction: "first", withinRange: true}.
Result: frame stays 1 and playing stays true; subsequent tick advances to 2.
Correct: playing false, frame 1, playback.stopped reason navigation.
This also applies to currentFrame.set of the already-current frame.

### C51A-R1S-02 (P2): equal relative plans accept changed drag content

Citation: E-10; reviews/M5-design-timeline-kernel.md section 5.2 requires
cell sources still hold grabbed drawings and bars commit the previewed result.
Path: timing_gesture.rs:410-431 emits only elementIds/startDelta for a body
move; :783-797 compares commands, not their resolved effects.
Input: selected peg bar start 1 duration 50, zoom 6 (16 px/frame), press
x=160,y=16, release x=192,y=16. Between press/release set its start to 2.
Both hit tests remain BarBody; both plans say startDelta:2 on the same id.
Result: commits start 4, whereas the press-time preview implies start 3.
Correct: cancel timeline.targetChanged. A command equality check alone does
not prove equality of relative-command results.

### C51A-R1S-03 (P2): setting another scene's range emits no range event

Citation: spec/A_command_registry.md:886 (playback.range.changed: range or
mode changed, payload sceneId/mode/start/end); SI-202 same events for range.
Path: commands/playback.rs:729-732 resolves optional sceneId and writes that
scene via set_range. settle_timeline in commands/playback.rs:329-338 only
compares the current scene's effective range with range_before.
Input: current scene A, scene B length 60; playback.range.set
{sceneId: B, start: 20, end: 30}. B starts in automatic mode.
Result: B changes to free 20..30, but no playback.range.changed is emitted.
Correct: emit playback.range.changed for B with free/20/30, without navigating
or changing selection. Agents observing B cannot learn of this change.

### C51A-R1S-04 (P2): structured paste ignores automatic extension

Citation: spec/01_application_shell.md:543 (Extend exposure automatically);
E-17 item 4 and E-19 require equality with every member stored.
Path: commands/edit_ops.rs:1382-1388 fills the gap with the last drawing when
extendExposures is true; commands/cell.rs:1750-1756 calls insert/overwrite
without extending the source frames or reading opts.auto_extend.
Input: destination has drawing A exposed only at frame 1; clipboard contains
one different drawing B. Store all paste fields, with autoExtend true and
exposure true. Set the current destination frame to 5 and paste, once by
edit.pasteSpecial and separately from the same state by cell.clipboard.apply.
Result: special paste fills frames 2..4 with A; structured paste leaves them
blank. Correct: both extend A to frame 4 before inserting B at frame 5.

### C51A-R1S-05 (P1): next drawing at the last frame panics

Citation: spec/09_playback_export.md:135-136, navigation at the range end
must do nothing and never wrap; SI-202/E-4 share drawing stepping.
Path: commands/timeline.rs:337 uses marks.range(f + 1..=hi) with no end guard;
:380 calls drawing_step for Next/Drawing, also reached by app.frame.move.
Input: scene length 60, current frame 60, timeline.currentFrame.move
{direction: "next", unit: "drawing"}. A current drawing element is present.
Result: constructs inclusive BTreeSet range 61..=60. Its start exceeds its
end, causing a panic rather than returning frame 60/moved false.
Correct: detect the boundary and return the unchanged frame before range().
This is a static standard-library precondition violation, not a run receipt.

## Observations

- Declarations: playback.start adds a minimum of 1 to fromFrame although
  spec A:891 says optional int without that bound. The handler clamps it.
  timeline.currentFrame.move adds count bounds 1..100000 (A:477 says int).
  These schema restrictions warrant reconciliation; no execution claimed.

- Host notices: crates/mcp/src/server.rs:1943 drops every event whose name
  starts with shell. before MCP delivery. That covers playbackFrame and
  timelineView. c44a_shell_notices.rs exercises the generic boundary using
  other shell notices; the C51 tests do not exercise these two on an MCP stream.
- The clock uses an unbounded channel; posting cannot wait on executor work.
  Generation checks in run.rs:2183 reject stopped-run ticks. The timer uses
  deadlines relative to its start rather than sleep-after-work scheduling.
- Tests: c51_gestures.rs:221 uses a 60-second recv_timeout state wait, not a
  sleep; rows-list assertions use a 150x ratio and a two-second gross ceiling.
  No direct unwrap(), expect(), panic!, unsafe or allow attribute found in
  the six new hand-written product modules scanned. Replay is product gesture
  interpretation, not a simulated-clock test hook.
- xsheet_pixels (render.rs:872-903) uses column_order and visible_in_xsheet,
  restricts types to Drawing/Image, and applies one drawing-space map without
  camera or peg transforms. Its test checks reorder/visibility and repeatability;
  it does not independently check pixel colours or camera independence.
- E-18 evidence contains the old/new hashes, counts and a description of a
  temporary uncommitted computation. It does not contain the event streams or
  an independently reproducible comparison. It records the claimed proof;
  this static session cannot verify the hash equivalence from that file alone.
- deferred.json has 100 entries and exactly the handoff owner counts:
  C5.1 40, C5.2 24, C6.2 17, C6.1 1, C7.1 6, C8.3 5, C8.1 1,
  C9.1 2, C10.1 2, C10.2 2. C5.1 refers to its pending window half under
  the split ruling. No passed earlier milestone appears among the owners.
- Scope limit: this is a focused static review, not a proof of every parameter,
  event payload or every transfer scenario. Generated schemas and inventories
  were inspected selectively; no runtime, timing or image result is claimed.
