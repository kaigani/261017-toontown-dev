## Findings

### C51A-R1S-01 (P2): navigation that keeps the frame does not stop playback

Citation: spec/09_playback_export.md:138, navigation stops playback first.
Path: commands/timeline.rs:361-387 marks navigation and writes the frame;
commands/playback.rs:317-320 stops only if frame_changed (or scene changed).
Input: loop playback in a 1..60 range, current frame 1, invoke
 timeline.currentFrame.move {direction: "first", withinRange: true}.
Result: frame stays 1 and playing stays true; subsequent tick advances to 2.
Correct: playing false, frame 1, playback.stopped reason navigation.
This also applies to currentFrame.set of the already-current frame.

### C51A-R1S-02 (P2): equal relative plans accept changed drag content

Citation: E-10; reviews/M5-design-timeline-kernel.md section 5.2 requires
cell sources still hold grabbed drawings and bars commit the previewed result.
Path: timing_gesture.rs:426-451 emits only elementIds/startDelta for a body
move; :783-797 compares commands, not their resolved effects.
Input: selected peg bar start 1 duration 50, zoom 6 (16 px/frame), press
x=160,y=16, release x=192,y=16. Between press/release set its start to 2.
Both hit tests remain BarBody; both plans say startDelta:2 on the same id.
Result: commits start 4, whereas the press-time preview implies start 3.
Correct: cancel timeline.targetChanged. A command equality check alone does
not prove equality of relative-command results.

### C51A-R1S-03 (P2): setting another scene's range emits no range event

Citation: spec/A_command_registry.md:886 (playback.range.changed: range or
mode changed, payload sceneId/mode/start/end); SI-202 same events for range.
Path: commands/playback.rs:704-707 resolves optional sceneId and writes that
scene via set_range. settle_timeline in commands/playback.rs:360-371 only
compares the current scene's effective range with range_before.
Input: current scene A, scene B length 60; playback.range.set
{sceneId: B, start: 20, end: 30}. B starts in automatic mode.
Result: B changes to free 20..30, but no playback.range.changed is emitted.
Correct: emit playback.range.changed for B with free/20/30, without navigating
or changing selection. Agents observing B cannot learn of this change.

### C51A-R1S-04 (P2): structured paste ignores automatic extension

Citation: spec/01_application_shell.md:542 (Extend exposure automatically);
E-17 item 4 and E-19 require equality with every member stored.
Path: commands/edit_ops.rs:1382-1388 fills the gap with the last drawing when
extendExposures is true; commands/cell.rs:1750-1756 calls insert/overwrite
without extending the source frames or reading opts.auto_extend.
Input: destination has drawing A exposed only at frame 1; clipboard contains
one different drawing B. Store all paste fields, with autoExtend true and
exposure true. Set the current destination frame to 5 and paste, once by
edit.pasteSpecial and separately from the same state by cell.clipboard.apply.
Result: special paste fills frames 2..4 with A; structured paste leaves them
blank. Correct: both extend A to frame 4 before inserting B at frame 5.

  These schema restrictions warrant reconciliation; no execution claimed.
