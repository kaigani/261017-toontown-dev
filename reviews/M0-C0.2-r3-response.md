## C02-R3-01 — missing run records accepted as manual — **fixed**

- **The page declares how the log came about.** `TabletSpike.tsx` writes `source`:
  - `auto` for `--spike-auto`;
  - `interactive` when synthetic strokes were injected from the toolbar;
  - `manual` when no synthetic stroke was injected (a hardware capture).
- **Outcome (b) needs the declaration.** In `scripts/analyse-tablet-log.py`, `is_manual` runs before any output.
  For a versioned log, outcome (b) is chosen only when **all** of these hold:
  - `source` is `"manual"`;
  - there are no run entries;
  - there are no simulation entries;
  - `environment.mode.auto` is not true.
- **Everything else is malformed** (exit 2, stdout empty):
  - simulation entries without run records ("synthetic evidence without its runs is missing evidence, not a manual
    capture");
  - a `--spike-auto` log without runs;
  - a log without runs that does not declare `source: "manual"`, which covers every v2 log and every v3 log written
    before this field;
  - a `manual` log that has runs;
  - an unknown `source`;
  - a simulation entry with no run record carrying the identical raw report. Validity is never recovered from saved
    simulation summaries; runs are still validated and recomputed from their raw records.
- **Versionless logs** are accepted only with no synthetic field whatsoever: no `runs` or `simulations` key (even
  empty), no `source`, no `environment.mode.auto`. The immutable round-1 fixture still passes.
  `analyzer.test.ts` checks that each of those five fields alone makes a versionless log exit 2.
- **Unaffected:** genuine declared manual logs, explicitly failed runs (outcome a) and all five committed matrix
  logs still analyse.

## C02-R3-02 — empty v3 focus records — **fixed**

A version-3 run now needs exactly one `start` and one `end` focus snapshot, each with integer `ownPid`,
`targetHwnd`, `foregroundHwnd`, `foregroundPid`, `focusHwnd`, `focusPid`, `activeHwnd` and `captureHwnd`, and string
`foregroundClass` and `focusClass`. An empty list, a single snapshot or a malformed field exits 2 (tested). The "not
recorded" label now reads "version 2 log; focus snapshots were added in version 3" and can only occur for v2.

## C02-R3-03 — lost range included received frames — **fixed**

- **Analyzer:** every match now carries `missingRuns`, runs of consecutive missing frame ids
  (`[first, last, count]`, longest first). Each run's line prints the longest of them next to the full
  missing-frame list. Tested.
- **Handoff:** corrected from that output. In matrix 5's sine 240 Hz run, 154 of the 156 frames 867–1022 are
  missing, and frames 905 and 1005 were received. The analyzer prints the runs as 906–1004 (99), 867–904 (38),
  1006–1022 (17), then 2–3 and the single frames 92, 408, 421 and 604. The listener-matrix cell lists the three
  disjoint ranges. The stall statement is qualified: the log cannot assign every loss in the span to a runner stall.
