# M2 C2.2 round 1 — block

**Verdict: block. 0 P0, 9 P1, 2 P2.** Target `648e22d35cbcd36bf163d554246d6bb0c9ed7039`, base `812554b`, branch `review/m2-c22-r1`. Product code and spec are unchanged. The new regression tests assert required behaviour and intentionally fail on the handoff.

The map cannot yet serve as C2.3's fill/topology foundation: small deterministic cases fail shared-anchor, overlap inheritance and zone-identity requirements. Paint targeting/mapping and colour recovery have further correctness divergences.

The [conformance register](evidence/M2-C2.2-r1/conformance.md) has **345 source units: 154 implemented, 36 divergent, 0 missing, 155 deferred with an owner**. Units are numbered/bulleted rules, table rows, normative paragraphs and zone/side JSON fields, not 345 independent passing tests. Its separate command register covers **52 declarations: 11 implemented, 41 placeholders**. [Live contracts](evidence/M2-C2.2-r1/command-contracts.json) retain parameter/result schemas, scopes, undo labels, enablement and examples. Mixed clauses are divergent when a required current-checkpoint part fails. Later renderer/UI/palette/template work retains its named checkpoint.

## Findings

### C22-R1-01 — P1: near-anchor noding does not share one junction coordinate

**Location:** `crates/vector/src/planar/node.rs:247–254` (`near_anchor`/`apply`). Repro: an unchanged pencil has anchors `(0,0), (5,0), (10,0)`; add a vertical pencil `(5.01,-5)→(5.01,5)`. Both split, but the old stroke's junction is `(5,0)` and the new one's `(5.01,0)`. Resolution independently preserves the old anchor on one participant and uses the raw crossing on the other. A derived snap graph does not make persisted anchors equal.

**Required:** 02 §3.12(1), readiness 3/5, ADR-0017 §1: exact shared junction anchors, surviving unchanged anchors authoritative, changed geometry meeting the same junction. Resolve the junction once for every participant, including near-anchor crossings/T-junctions.

**Regression:** `crates/vector/tests/c22_r1_geometry.rs::a_crossing_near_an_existing_anchor_has_one_shared_junction`. Observed `5.0 != 5.01`; [geometry log](evidence/M2-C2.2-r1/geometry.log).

### C22-R1-02 — P1: overlap inheritance omits intersecting zones

**Location:** `crates/vector/src/planar/fill.rs:239–264`. Repro: old red rectangle `[0,10] × [4,6]`; new rectangle `[1,3] × [0,10]` with changed boundary IDs. Exact overlap is 4 du², but `carry` returns `None`. Old interior `(5,4.1484375)` and new interior `(2,0.7109375)` lie outside the opposite rectangles. Candidate selection only admits zones containing an interior point, so exact polygon intersection never sees this pair; it can likewise omit the largest-overlap winner when other candidates exist.

**Required:** 02 §3.12(1), readiness 6, binding SI-060: largest exact overlap, lower old-ID tie. Candidate enumeration must conservatively include every positive-area overlap.

**Regression:** `c22_r1_geometry::overlapping_zones_carry_fill_even_when_neither_interior_point_is_in_the_other`; [geometry log](evidence/M2-C2.2-r1/geometry.log).

### C22-R1-03 — P1: changed boundary geometry retains its zone ID

**Location:** `crates/vector/src/planar/graph.rs:902–920`. Repro: reshape one closed pencil rectangle `(0,0)–(10,10)` to `(0,0)–(20,10)`, retaining its stroke ID. Both zones are `zn_YEA8XJG3D5S6B5JJEV6R1ZX3B0`. Pencil hash tokens contain only IDs/sides, not geometry. `fill::carry` also then treats these boundaries as identical before overlap scoring.

**Required:** 02 §3.12(4), 03 §16.1(5), readiness 5/8: zone identity derives from geometry and changes whenever its boundary changes. SHA-256 is suitable; its canonical input is incomplete. Include boundary geometry while preserving unrelated-edit and cross-OS stability.

**Regression:** `c22_r1_geometry::changing_a_boundarys_geometry_changes_its_zone_id`; [geometry log](evidence/M2-C2.2-r1/geometry.log).

### C22-R1-04 — P1: path painting skips crossed narrow zones

**Location:** `crates/executor/src/commands/colour.rs:641–655`. Executor repro: invisible rectangle `x=1000.1..1000.2, y=1000..1002`; paint path `(999,1001)→(1001,1001)`. The continuous path crosses it, but 0.5-du samples miss it and return `colour.noTarget`. The 10,000-sample clamp makes intervals larger for long paths.

**Required:** 03 §8.2 solid-drag rule, §16.1(4), spec A `colour.paint.apply`: paint every crossed zone/line in one step. Use continuous arrangement traversal or conservative intersection tests. Each sample also gets a fresh hit-test work budget; the path lacks a shared aggregate geometric work account. A layer-refusal ceiling does not prove arbitrary path-command latency bounded.

**Regression:** `crates/executor/tests/c22_r1_commands.rs::crossing_path_paints_a_zone_between_sample_positions`; [commands](evidence/M2-C2.2-r1/commands.log).

## Independent oracle and code/numerical review

The reviewer constructs convex cells by clipping a square against fixed-seed lines independently of engine graph/face/point-location data. It compares count, area and membership. Cases containing cells below 1 du² are excluded from that comparison to avoid asserting an unsnapped sliver survives a 1/64 grid. Analytic controls cover nested holes/parents, left/right assignments on both pencil boundaries, coincident retracing, point tangency and a bridged O-shaped brush contour (band winding versus hole). Builder SI-053 independent swept-union tests extend the brush corpus. Text/bitmap roles use C2.1 tests, not an arrangement approximation.

A snap probe collapses a 10×0.004-du rectangle and retains 10×0.016 at area 10/64 du², repeatably. This deterministic sub-grid topology change conforms to ADR-0017's chosen representation; it does not establish exact real-coordinate topology. R1-01 separately violates the exact persisted-anchor invariant. New reviewer geometry tests have not run on Mac.

At ±10⁷ du, 1/64 grid coordinates are ≤640,000,000; differences ≤1,280,000,000; determinants <3.28×10¹⁸; crossing rational products <4.20×10²⁷. Even at 1/128, products <3.36×10²⁸ fit i128 (≈1.70×10³⁸). Bounded polygon accumulation fits; 1/64 coordinates fit i32 for i_overlay. This does not establish all flattening-error bounds: the 4096-piece cap and extreme-coordinate near-tangent curves need further coverage.

`node` sorts HashMap cells before output-affecting traversal. `graph` hash-cell traversal only fills an ordered hot-pixel set; accepted graph output derives from sorted vertices/pieces. First refusal charge can vary with hash order, so observed refusal units are not canonical geometry. No forbidden unsafe/allow/unwrap()/expect()/panic! occurs before cfg(test) in reviewed new geometry/colour/cache modules; test panics are assertions. [Static audit](evidence/M2-C2.2-r1/static-audit.txt).

`Cx::settle` (`cx.rs:687`) precedes preview/final commit and uses validated staging/patching, including generic patches. Dry runs may warm cache but commit no document/event. Undo/redo/restore install recorded states. Cache hashes IDs/kind/closed/points with separators, intentionally excludes fills, and compares model values first for untouched layers. SHA-256 collision is not a practical invalidation concern; geometry omission in **zone identity**, R1-03, is a different issue. Cache geometry keys include geometry.

Only existing workspace sha2 dependencies were added to vector/executor: no new resolved package/version. CI cargo-deny/release feature checks are green; reviewed changes introduce no test-hooks into product graph. The brush bridge filter preserves exact candidates/tie ordering; its nested nearest-pair search remains quadratic in the worst case despite the handoff's linear wording.

## Performance adjudication

**C22-T2 is a legitimate C2.4 performance deferral under plan §4, C21-R1-12 and the M11 C11.1 final gate.** 02 §3.12 requires a correctly re-noded affected layer after each edit; it does not mandate rebuilding every unchanged segment. Incremental indexes/local face updates are conformant if global topology, identities, budgets and exact inverses remain correct.

The release geometry corpus's 10 s ceiling passes on both CI OSes and locally; successful named CI observations peak below the default 30 s reply watchdog. Post-warm-up growth guard passes. Code limits 512 maps and 8,000,000 vertices+half-edges via deterministic LRU; strings/sources/rings/faces/indexes are not counted, and one over-cost map can remain. The serialized worker can delay maintenance/autosave during a ~22 s edit, even while the caller is inside the watchdog. Existing queue/autosave tests do not establish low-latency responsiveness on this enlarged path. Preserve R1-12's allocation/OS-memory/queue evidence and C2.4/M11 gates. The performance deferral does not excuse R1-04's absent shared path-work accounting.
