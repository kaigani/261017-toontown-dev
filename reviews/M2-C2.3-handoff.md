## 2. Engine rulings applied

- **Flatten policy:** `policy {precedence: upper|lower, position: top|bottom}`, so M4 auto-flatten and Draw Behind use
  the same command (SI-073).
- **Cut primitives:** cut-by-polygon (`polygon`, `rect`) and cut-by-segment (`segment`) on `draw.cut.apply`, each with
  an executable example. Spec A has a closed command list, so the primitive is a parameter, not a new ID (SI-071).
- **Point-subset transforms:** `draw.transform.apply {points}` (or the Contour Editor's point selection when no
  object is selected) moves only those anchors, with pivots at their own bounds; `draw.point.set` handle pull-out
  (symmetric, broken, reset); `draw.point.move` moves shared junction anchors together and snaps to contour (SI-070).

## 3. Declared edits

1. **Reviewer-tooling P2 (explicit permission).** `crates/executor/tests/c13_r2_persistence.rs` (runs a temporary copy
   of the inspection probe unless `TT_COMMIT_REVIEW_RECEIPTS=1`) and `c13_r3_persistence.rs` (writes the open-latency
   receipt to the temp directory unless `TT_COMMIT_REVIEW_RECEIPTS=1`). Assertions and computed values are unchanged.
   The diff is [evidence/M2-C2.3/reviewer-tooling-p2.diff](evidence/M2-C2.3/reviewer-tooling-p2.diff) (commit `a85bac3`).
   The two committed receipts are now untouched by routine runs.
2. **Builder tests updated** (not reviewer-owned):
   - `c21_obligations.rs::c21_drawing_commands_write_no_files_and_ask_no_confirmation` now covers every implemented
     `draw.*` command, accepts UI scope, tells an eraser point path from a file path, and names two declared
     exceptions (`draw.inspectorPreview.set`: prefs scope; `draw.drawing.render`: optional file output checked against
     `files.write`).
   - `tt_vector::ops::transform` unit test for spines now expects rigid motions to keep the spine.
   - `c12_policy.rs::permissions_validation_and_availability` used `draw.flatten.apply` as its not-implemented example;
     it now uses `draw.vectorize.preview` (owner M2 C2.4).
3. **Behaviour change in existing commands:**
   - Transforms of whole layers repaint their zones with mapped fill matrices, so textures and gradients turn with the
     geometry (found by the render tile-axis test).
   - `regenerate`, `pen_choice`, the colour helpers `resolve_colour`, `swatch_info`, `tile_size` and `paint_matrix`, and
     `set_drawing_selection` became `pub(crate)` for reuse.
   - The MCP `render_drawing` tool defaults `width` to 512; the MCP docs no longer say drawing renders arrive in M3.
4. **Dependencies:** `tt-render` takes `vello_cpu =0.3.0`, `fearless_simd =0.7.0` and `png =0.18.1` as normal
   dependencies (ADR-0006 pins), and `tt-executor` depends on `tt-render`. No new crate enters `Cargo.lock`.
5. **No reviewer-owned file changed** apart from item 1. The allow inventory is unchanged at 98 lints in 40 files.
