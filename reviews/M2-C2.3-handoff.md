## 2. Engine rulings applied

- **Flatten policy:** `policy {precedence: upper|lower, position: top|bottom}`, so M4 auto-flatten and Draw Behind use
  the same command (SI-073).
- **Cut primitives:** cut-by-polygon (`polygon`, `rect`) and cut-by-segment (`segment`) on `draw.cut.apply`, each with
  an executable example. Spec A has a closed command list, so the primitive is a parameter, not a new ID (SI-071).
- **Point-subset transforms:** `draw.transform.apply {points}` (or the Contour Editor's point selection when no
  object is selected) moves only those anchors, with pivots at their own bounds; `draw.point.set` handle pull-out
  (symmetric, broken, reset); `draw.point.move` moves shared junction anchors together and snaps to contour (SI-070).

    pass, which charges the planar work account (C2.2).
