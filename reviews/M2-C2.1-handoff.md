## 1. What was built

**Obligation 1 (before C2.1).** Every declared example of every implemented command is executed on the fixture
project and its result is kept in `crates/registry/src/example-results.json`; `describe_command` returns it as
`examples[i].result` (with `resultVaries`, the pointers that differ between runs; results over 32 KiB as a
`resultDigest`). Worked end-to-end examples for **project, doc, edit, checkpoint, job, agent and app** run through the
real MCP server and are kept in `crates/mcp/src/worked-examples.json`; `app://docs/<ns>` renders them under
"## Worked example". Both recorders execute twice to find varying values (ids, times, tokens, font-dependent text
bounds) and re-check on every OS that each example still reproduces its retained result and satisfies its result and
envelope schemas. The retained ticket `namespace_docs_carry_a_worked_example_with_executed_results` passes (its
`#[ignore]` is removed; body unchanged since `5983f29`).

**`tt-vector`** (pure library over the `tt-model` entities; ADR-0016):

| Module | 02 § | What |
|---|---|---|
| `num`, `geom` | ADR-0004 | IEEE `+ − × ÷ sqrt` only; sin/cos/acos from pure-software `libm` (bit patterns pinned); cubic eval/split/exact bounds/arc length (Gauss–Legendre)/flatten |
| `path` | 13.4, 10 §4.9 | persisted anchors ↔ Bézier lists, validation (`drawing.invalidGeometry` with pointers, ±10⁷ du, ≤ 100 000 anchors) |
| `fit` | 3.3 | dedupe, corners (> 60°), least squares + Newton, split at max error, tolerance 0.25 + 0.5 s, pressure smoothing, (t, p) by spine arc length |
| `brush` | 3.4 | tip sweep (round/oval/square/flat, tip angle), width = min + p(max − min), clean union on a 1/64 du integer grid (`i_overlay`), dabs, bridged single contour (SI-053), densified then fitted |
| `stroke` | 3.2 | building and editing persisted strokes; spine re-sweep; tip angle in `ext["dev.toontown.brush"]` (SI-054) |
| `symmetry` | 6.2 | Mirror and Kaleidoscope maps (2n images) |
| `text`, `fonts` | 3.7, 7.6 | code-point edits with runs/paragraphs, formats, layout (advances, `kern` pairs via `skrifa`, wrap), system fonts (`fontdb`) |
| `drawing`, `content` | 3.1, 3.6, 3.9, 13.4 | lookup through groups, layer policies, bounds, read-back with a closed schema, §13.4 content input |
| `invariants` | 3.12 | ID uniqueness, untouched objects preserved, geometry/text/bitmap well-formedness |

**Commands** (hand-written in `crates/executor/src/commands/draw*.rs`, replacing their generated SI-026
declarations; examples executed on the fixture; results schema-checked):

| Command | Notes |
|---|---|
| `draw.drawing.get` | §13.4 shape, `include`/`flatten`/`ids`; zones absent + `doc.derivedUnavailable` (SI-057); > 32 MiB → `limit.exceeded` |
| `draw.current.get` | `activeView` typed as `AppState.activeView` |
| `draw.stroke.add` | brush/pencil/invisible, points (fit or straight) or verbatim Béziers, pressure map, pen/penId, layer auto/new/top/behind/id, symmetry path, createDrawing, labels "Brush/Pencil/Stroke Tool", hint `drawing.strokesHidden` |
| `draw.stroke.set` | spine/outline/path geometry, pressure, thickness, pencil ↔ invisible; ID kept |
| `draw.object.delete` | nodes and strokes; a layer emptied of strokes goes too |
| `draw.pivot.set` | "Change Drawing Pivot" |
| `draw.group.create` / `.delete` | one node list; strokes move into a new layer in the group; ungroup restores place and order |
| `draw.text.add` / `.set` / `draw.textFormat.set` | runs and paragraphs, labels per 02 §12.1, bounds, `drawing.fontMissing`; `outlineColourId` only `null` (SI-055) |
| `draw.content.add` | §13.4 shape (a read-back is accepted), new IDs, colours kept (`colour.unresolved` until C2.2), bitmaps of document images (SI-052) |

All take `drawingId` / `elementId` + `frame` / current drawing; creation commands take `createDrawing`; ID edits take
`expectRev` → `drawing.staleRevision` (SI-056). Every change goes through `Cx::patch_entries` and the full integrity
gate. `doc.object.patch` on strokes runs the same normalisation (spine edit re-sweeps the outline, outline edit drops
the spine, geometry checked; 02 §13.6). `doc.validate` `missingFonts` reports uninstalled fonts (no longer
"unavailable"). The zones derived-field owner is corrected to M2 C2.2.

**Bounded snapshots (obligations 4, 11).** Measuring showed every committed edit of a 100 000-stroke drawing kept a
full copy of the re-parsed drawing in the revision log (256 snapshots). The log now keeps snapshots newest first while
the objects they alone hold fit `SNAPSHOT_OBJECT_BUDGET` = 400 000 (the newest is always kept); older records use
their back-patches, so `doc.diff` stays exact. Process memory levels off (§4).

**CI (orchestrator ruling).** The headless release build, self-test (twice, compared), linked-library proof and the
release SDK conformance moved from `check` into a new `headless release (windows/macOS)` job (55 min), which also runs
the release 100k-stroke measurement and its analyzer. `check` keeps every test step and reviewer suite, and runs the
official SDK conformance against the debug headless binary plus the C1.4 measurement analysis and release-feature
proof. `check` stays at 60 min. Reason: run 41105899189 on `main` cancelled `check (windows-latest)` at 60 min in the
release build on a cold cache.

## 2. How to run and test

```
cargo test -p tt-vector                                   # unit + property tests (fixed ChaCha seed)
cargo test -p tt-executor --test c21_draw --test c21_obligations --test c21_determinism --test c21_example_results
cargo test -p tt-mcp --test c21_replay --test c21_history --test c21_worked_examples --test c14_tickets
cargo test --release -p tt-executor --test c21_measurements -- --ignored --nocapture
python scripts/analyse-measurements.py target/evidence/c21
TT_RECORD_EXAMPLES=1 / TT_UPDATE_GOLDEN=1                 # re-record retained examples / the determinism digest
```

Through MCP: `toontown-headless --mcp-stdio`, then `run_command` with e.g.
`{"id": "draw.stroke.add", "params": {"elementId": "scene:#1/element:\"Bob\"", "frame": 1, "points": [...]}}` and
`draw.drawing.get` to read back.

## 4. Measured numbers (raw observations kept)

100 000-stroke drawing (fixture seed 1, drawing 1, layer 1 of pencil strokes), release, Windows x86_64, 32 CPUs,
10 repetitions, `crates/executor/tests/c21_measurements.rs`, recomputed by `scripts/analyse-measurements.py`
([evidence](evidence/M2-C2.1/)):

| Call | wall p50 / p90 / max | allocated per call p50 | retained per call p50 / max |
|---|---|---|---|
| `draw.stroke.add` (pencil, into the 100k layer) | 4 792 / 4 991 / 5 090 ms | 3 338 MB | 0 / 121 MB |
| `edit.undo` | 5 489 / 5 631 / 5 702 ms | 3 963 MB | 0 / 121 MB |
| `edit.redo` | 4 639 / 4 881 / 5 025 ms | 3 310 MB | 0 / 121 MB |
| `draw.stroke.add` dry run | 4 825 / 5 264 / 5 445 ms | 3 338 MB | 0 / 0 MB |
| `draw.stroke.set` | 4 605 / 4 797 / 5 083 ms | 3 256 MB | 0 / 0 MB |
| `draw.stroke.add` (brush, new layer) | 4 605 / 4 650 / 4 829 ms | 3 235 MB | 0 / 0 MB |
| `doc.object.patch` on one stroke (M1 property path, comparison) | 3 415 / 3 442 / 3 468 ms | 2 457 MB | 0 / 0 MB |
| process live bytes after each call | p50 496 MB, max 510 MB over 70 calls (first 268 MB) | | |

"Retained" is allocated minus freed during the call (the snapshot a commit adds; 121 MB = one copy of the drawing
until the budget evicts an older one). The drawing commands' structural change records cost ≈ 1.2 s more than the
property path; the rest is the C1.1 staged commit.

The cost is the coarse whole-entry staged commit of C1.1/C1.2 (the drawing entry is serialised, re-parsed through the
full input path, diffed and stamped as a whole). Node-granular staging that keeps the gate whole is the M2 C2.4
performance work (plan §4: "performance targets of plan §4 for 100 k strokes"). Before the snapshot budget, each
committed edit retained ≈ 121 MB (one drawing copy) for up to 256 snapshots.
