## Numeric inputs converted to the one numeric field (D-61 item 3)

`desktop/src/shell/NumericField.tsx`: strict parsing; empty or non-numeric entries send nothing and restore; the
command's declared range (`declaredRange`, read from the generated schema) refuses out-of-range values with the reason
shown; Enter and focus loss commit; Escape restores; the display is the retained value; a command's refusal restores
and shows its message. A text input with `inputMode="decimal"` (a `type="number"` input reports letters as empty).
`scripts/test_c43_d39_inventory.py` fails if any product source builds a `type="number"` input again.

## Reviewer files edited (declared, ruling D-60 item 3)

Each edit is exactly what the ruling authorised:

- `tests/adversarial/c42b-r1-conformance.py` `launch` (lines 16-20): seeds the agent defaults with `askInApp: false`
  before launching, the same seed as `scripts/mcp-conformance.py` `launch_desktop`.

  whose value needs its row's setup (it raises `LookupError` or `TypeError` before the setup ran) is not one of this
  probe's rows and is skipped, as the probe skips every row it does not want.

  timeout message names the limit that applied.

  `element.list`) current at frame 1 with `app.context.set`.

  "different option" step.
