## The CI schema-failure adjudication: local-gate gap closed

The review is right that "every example ran" did not mean every implemented example succeeded and had its result
checked on Windows.

**What changed.** The example runner in `c12_kernel_state.rs::every_example_runs_on_the_fixture_under_the_watchdog`
already ran every implemented example with the `/tmp` paths mapped into a temporary folder, on a file-backed
fixture, and required success except for the classified cases (event, `notImplemented`). It now also:
- validates every successful result against the command's declared result schema;
- validates the envelope against its schema;
- for job commands, waits for the job and requires `succeeded` (the job table checks the final result against
  `x-jobResult`).

**Result.** 809 examples run and 117 successful results are schema-checked on Windows, where before none of the
`/tmp` examples were.

**Negative control.** Reverting the `omitted` fix makes this test fail on Windows with `"omitted" is a required
property`, the exact macOS-only failure of run 41032165473. (`ce869ce`)
