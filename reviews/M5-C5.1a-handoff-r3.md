### 8.6 The macOS drawing byte gate, run 45174410122 (`5c3005e9`)

- **Cause:** `scripts/c43-gesture-equivalence.py` read the window's Camera view size, 920 x 310, stable over two reads
  0.5 s apart, and started engine 2 with it. The window's layout then narrowed the view to 861 px (the width every other
  macOS run reports) before the first gesture: every recorded gesture carries the window's mapping with centre 430.5, so
  engine 2 (centre 460) placed every replayed point 18.4375 drawing units (29.5 px) to the left. The corner, skew and
  pivot presses missed their handles (Move instead of Scale, Skew, Move Pivot); the drawing tools' points were offset.
  The first three rows passed only because a click and two relative moves do not depend on the offset. No product
  change; the window and the direct commands agreed in every row.
- **What the three byte-gate failures of C5.1a share:** the canvas's mapping read answered by the older mount read
  (run 45082297045, a product defect, fixed with the read gate); the `c44b` script reading sizes before the views had
  reported them (run 45114345189); this one. Each took the window's view geometry at one moment and assumed it still
  held when the gestures were mapped. The window lays out asynchronously, so a longer wait narrows the race and cannot
  close it.
- **The gate's design changes:** the geometry is checked per gesture, against the mapping the window recorded with that
  gesture (`c43.geometry_at_gesture`, used by `c43` and `c44b`; `c42` already replays every row through the recorded
  mapping). When engine 2's view maps the same, the replay is in view space and compared exactly (D-32, unchanged). When
  it does not, the row replays through the recorded mapping within the stated tolerance, and the row
  (`geometryChanged`: both mappings, both sizes) and the manifest (`geometryChanged`) name it. Engine 2 is not restarted
  at the new size: the rows run in lockstep (each is undone on all three engines; the content compared includes
  revisions and ids), which a freshly opened engine would break. The window's recorded mapping is the kernel's own
  (`desktop/src/canvas/geometry.ts`: the canvas never derives one), so on a settled layout the two are bit-identical
  and the exact path runs as before (green runs: `replayNotExact` empty). The reviewer probe that patches
  `c43.main`'s source (`tests/adversarial/c43b-r1-live.py`) keeps every anchor it uses. Merge note §4.
