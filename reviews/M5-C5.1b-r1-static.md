## Findings

### C51B-R1S-01 - P2 - Show Timeline Selection never reveals the row

Citation: plan section 5 line 155; SI-216; design view section 1.
Code: desktop/src/timeline/TimelinePanel.tsx:390-398, 156, 651;
crates/executor/src/commands/timeline.rs:1125.
Sequence: scroll a long list to its top; an agent makes a bottom element
current, then invokes timeline.view.set with revealElementId null (or use /).
The host notice carries revealElementId, but the panel only parses view and
uses the rest to trigger reads. No code sets listRef.scrollTop for a reveal.
Wrong: the current row stays offscreen indefinitely. Correct: scroll the
requested row into the visible vertical window, including repeated reveals.

### C51B-R1S-02 - P2 - A rows answer can overwrite a newer playhead notice

Citation: plan section 5 lines 160-161; design view section 1 read-gate rule.
Code: desktop/src/timeline/TimelinePanel.tsx:226-230, 401-415, 181.
Sequence: a rows read snapshots frame 1; before its promise completes, a frame
change notice sets frameNow to 20. The rows answer then sets rows and clears
frameNow. Neither frame notice invalidates rowsGate or requests newer rows.
Wrong: after playback stops, the final frame can remain 1 with kernel frame
20 and no later event to repair it. Correct: reconcile frame notices and rows
answers in one ordering domain; an older snapshot must not clear a newer frame.

### C51B-R1S-03 - P2 - Required context items absent

Citation: spec/04_timeline_xsheet.md:704-706; E-2, E-9;
design view section 5.
Code: desktop/src/timeline/menus.ts:91 (rowMenu), 455 (cellMenu),
550 (rulerMenu); TimelinePanel.tsx:1018 (menu rendering).
Sequence: right-click a drawing cell. The menu has only Cut/Copy/Paste/Delete;
none of the exposure, insert, cycle or duplicate-drawing placeholders exists.
Right-click a row: import items, Toggle Constant Z, Add Default Keyframe and
Edit Sound are absent. The ruler lacks Sound Playback and Sound Scrubbing.
The shared menu disables deferred references only if they were supplied; it
never adds missing items. Correct: required later-owned items remain present,
disabled with owner; currently owned Constant Z is bound (E-2).

### C51B-R1S-04 - P2 - Context toggles never show checked state

Citation: spec/04_timeline_xsheet.md:708; plan section 7 line 258.
Code: desktop/src/timeline/menus.ts:285 (effect parameters), 550 (rulerMenu);
desktop/src/shell/ContextMenu.tsx:365 (item.check determines checked display).
Sequence: set free playback range, then open ruler context. Automatic Fit and
Free have no check property, so neither shows current mode. Show Effect
Parameters likewise always says Show and sends visible true even when on.
Correct: mode choices show the current mode and the per-effect toggle shows
its current state and permits turning it off.

## Observations

Findings distinguish concrete code sequences from coverage concerns. Findings above are static event sequences, not live results.

- D-39 Timeline reasons: Peg Reset is registered but not implemented (M6 C6.1);
  context actions require real pointer/keyboard input (TL_CONTEXT_ONLY);
  canvas and menu geometry require the debugging port. The first is legitimate
  deferral; geometry needs real layout. Context actions being OS-only leaves
  CI without the promised end-to-end row for those controls: inventory tests
  inspect row names, not execution. timing-gui exercises gestures instead.
  Unit menu-model coverage cannot establish actual item reachability (R1S-03).
- Deferred owners inspected: none is C5.1 or earlier. Structured preference
  aliases and explicit cell clipboard forms have the E-4/E-5/E-6 reasons.
- reads.json carries Timeline reads on unrelated surfaces such as loadReport;
  declarations alone do not prove those surfaces actually mount the panel.
