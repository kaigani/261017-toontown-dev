## 7. Answers asked for

- **Grapheme clusters (D-78 item 8).** The session's positions are code points (Rust `char`s), as are the commands'
  (`draw.text.insert`, `draw.textFormat.set` ranges). A caret can therefore sit inside a cluster: between a base
  letter and a combining mark that NFC did not compose, inside an emoji ZWJ sequence or a flag, or before a variation
  selector; Backspace there removes one code point of the cluster. Not built: moving by extended grapheme clusters
  (UAX #29) for the caret keys, Shift selection, Backspace and Delete, double click and the hit test, with the commands
  staying code-point indexed (a cluster boundary is always a code-point boundary, so no command changes).
  `unicode-segmentation` 1.13.3 is already in `Cargo.lock` (through `tao`, MIT or Apache-2.0) but not in the kernel's
  tree; using it would add a direct dependency of `tt-vector`. Proposed for M11 C11.1 or as a P3 in a later round,
  with the user's agreement to the dependency; a design-note paragraph and a kernel test over a corpus (combining
  marks, ZWJ, flags, variation selectors) would come with it.
- **The inserted point's selection (D-79 item 4):** §6, l1b 6.
