### Front end (readiness bullet 1, ADR-0012)

- `desktop/src/ipc/generated/wire.ts` and `model.ts`: schemas and TypeScript types generated from the Rust types
  (`crates/engine/tests/frontend_schemas.rs` regenerates them and fails on drift). `wireSchemas.ts` now builds its
  guards on the generated definitions; `types.ts` re-exports the generated product types.
- Lossless JSON text transport: product IPC arguments go as `{json}` text, results come back as UTF-8 JSON bodies,
  errors and menu events as JSON text (`desktop/src-tauri/src/ipc.rs`, `menu.rs`, `crates/engine/src/wire.rs`).
  `wireJson.ts` parses strictly and losslessly (`bigint` beyond 2^53 − 1), with schema-directed coercion of
  digit-only doubles.
- `schema.ts`: draft 2020-12 keywords the generated schemas use, `$ref` via a definitions table, `bigint`-aware
  integers; own-property, dense-array, depth and validated-snapshot guarantees unchanged.
- **C01-R3-04 resolved**: `certify` runs the structured-clone algorithm through `MessageChannel` (Safari 15.0 floor)
  and rejects every Proxy. The three reviewer cases pass and are unmarked from `it.fails`; bodies unchanged.

## Known gaps (not narrowing the checkpoint; owner named)

1. **Revision stamping, transactions, undo/redo, `expectRev`, event emission**: the model provides `rev` fields, own
   views, diffs and inversion; stamping `rev` on commit and producing `ChangeSet`s per transaction is C1.2 (executor).
2. **Diff cost at 100 000 strokes** (1.5 s whole-entry): C1.2's transactions record which objects they touch and diff
   only those (and their parents' membership); measured again there.
3. **Derived properties in query results** (`include: ["derived"]`: scene length, usage, clone groups, …) are declared
   in the schemas with `x-derived`; computing them in `doc.object.get` is C1.2. `Document::scene_length` exists.
4. **Special references** (`@current`, `@selection`, …) return `ref.notFound` (`reason: noContext`) until C1.2
   supplies the application context through `ResolveContext`.
5. **Load path**: repairs (10 §7.2), migration, newer-minor handling with the overlay, unknown enum values (D12)
   are C1.3; `Document::assemble` + `issues()` provide detection now.
6. **New-project defaults** (01 §3.1: default palette of ~120 swatches, default pens, scene with camera and drawing
   element): `Pen::default_set` and the element/scene/project constructors exist; `project.create` assembles them in
   C1.3 (the default palette values are authored then).
7. **Effect type descriptors** (06 §8.4 `paramsSchema`, per-particle-type defaults and caps beyond fog/cloud) belong
   to `tt-fx` (M7); the static parameter sets of the five effect types are typed here.
8. **`jsonschema` is pinned to 0.18.3** with its `draft202012` feature: every later release depends on
   `borrow-or-share` (MIT-0). The keywords our schemas use are covered by tests; newer-keyword features
   (`unevaluated*`, `$dynamicRef`) are neither used nor relied on.
