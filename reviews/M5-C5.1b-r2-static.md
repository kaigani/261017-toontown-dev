## Findings

### C51B-R2S-01 - P2 - Shift+F10 bypasses modal and editing guards

Citation: spec/11_agent_interface_mcp.md:237-241, 360-362; E-48.
Code: crates/mcp/src/server.rs:1394-1402;
crates/executor/src/lib.rs:769-778;
desktop/src/shell/windowHooks.ts:132-145;
desktop/src/timeline/TimelinePanel.tsx:720-750.
Sequence: person opens a modal or is editing a text field; input-scoped agent
calls key with shift+F10 and view timeline.tracks. The early branch emits a
host notice without origin or modal/busy checks. The window focuses the canvas
and dispatches contextmenu; the Timeline handler opens its menu unconditionally.
Wrong: success and a focus-changing menu behind/over the person's dialog,
instead of ui.modalOpen (or ui.busy while editing). Correct: apply the ordinary
key coexistence checks before emitting any event and respect field ownership.

### C51B-R2S-02 - P2 - Shift+F10 reports nonexistent targets as handled

Citation: spec/11_agent_interface_mcp.md:355 (handled result), 360-362; E-48.
Code: crates/mcp/src/server.rs:1394-1405;
desktop/src/shell/windowHooks.ts:132-139.
Sequence: key shift+F10 with view timeline.deletedControl (or a stale row id).
The server immediately answers handled:true. No matching node exists, so the
window silently returns and no menu opens. A non-string view also silently
becomes the focused control. Correct: validate target type and existence and
return an error or handled:false when no context menu can be opened.
