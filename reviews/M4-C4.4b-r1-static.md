## C44B-R1S-01

Rule: SI-191 and text design note section 3 explicitly end a run on pending-format
changes. Location: text_edit.rs:787-830; run.rs:650-685.
Input: open empty text, type A, set bold using draw.textFormat.set with start 1,
length 0, then type B. take_pending only extends pending and emits a notice. It
neither ends history's run nor stages a document transaction. B's insertion therefore
extends A's existing Typing step, as does B's subsequent formatting command.
Expected: two Typing runs; observed by deduction: one, so Undo removes A as well.
Smallest fix: explicitly end the history run when accepting pending formatting.

## C44B-R1S-02

Rule: text design note section 7 promises the input path clamps to the session;
02 section 7.6 requires continued editing and SI-193 gives undo to the document.
Location: text_edit.rs:416-438, 654-675, 841-846; draw_text.rs:478-484.
Input: type ABC at caret 3, undo Typing (or have another origin replace ABC with A),

after content changes/undo/redo, before notification or another input; reset goal_x.

## C44B-R1S-03
