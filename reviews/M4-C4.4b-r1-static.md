## S1 - PASS

Read contour_gesture.rs and the contour handlers. Hit distances use the view mapping,
anchor/handle ties prefer anchors, stroke ties prefer front-most; segment insertion
uses the kernel parameter. Commands carry the drawing, point list, snap and view.
Deletion groups indices before mutation, removes undersized strokes in reverse list
order, and adjusts point indices. Reset guards zero directions, handles open ends
and wraps closed neighbours. Locked drawings refuse mutation. Escape cancels the
collector before command dispatch. The contours answer is proportional to selected
and junction-partner geometry, without an independent payload cap; the known large
stroke case is owned by M11 and is not reported again.

## S2 - PASS

One map is computed before the bank loop (draw_transform.rs:832-842), using the
exposed drawing at the requested/current frame for corners. The loop covers the
element's bank, including unexposed drawings, and skips/reports locked drawings;
empty drawings produce no patches. Other elements' banks are untouched. All entries
are patched in one transaction. Text and bitmap matrices use the three-corner affine
fit; pencil thickness uses that fit's scale, as SI-070/SI-190 permit. Auto chooses
affine for parallelograms, projective for strictly convex quads and bilinear otherwise.
Concave and crossed targets thus use bilinear. Singular projective solves refuse
drawing.invalidGeometry. Zero source extent is rejected on the bilinear path; the
affine shortcut clamps the source extent. These degenerate cases merit explicit
policy tests but no contrary invariant was established. The window port repeats the
same branches, corner order and elimination pivot tie rule.
