## C44B-R1S-01

Rule: SI-191 and text design note section 3 explicitly end a run on pending-format
changes. Location: text_edit.rs:787-830; run.rs:650-685.
Input: open empty text, type A, set bold using draw.textFormat.set with start 1,
length 0, then type B. take_pending only extends pending and emits a notice. It
neither ends history's run nor stages a document transaction. B's insertion therefore
extends A's existing Typing step, as does B's subsequent formatting command.
Expected: two Typing runs; observed by deduction: one, so Undo removes A as well.
Smallest fix: explicitly end the history run when accepting pending formatting.

## C44B-R1S-06

Rule: envelope design section 6/SI-190 promises the kernel map, exact at anchor
vertices. Location: webgl2.ts:26-28, webgpu.ts:38-40 versus
crates/vector/src/ops/transform.rs:145-149 and envelope.ts:190-194.
Input: source box [0,0,1,1], convex target [(0,0),(1,0),(0.5,1),(0,1)].
The projective map is (x/(y+1),2y/(y+1)). A stroke handle/control point outside
the box, or geometry in another drawing under Reposition All's shared map, can
have y=-1. For a vertex (1,-1), the kernel returns (1e12,-2e12) by clamping w;
both shaders divide by zero. The CPU port guards it, but packed GPU execution and
unpackApply do not. Expected identical guarded map; observed by deduction nonfinite
preview coordinates. Smallest fix: port the signed denominator guard into both
shaders and unpackApply, with a pole/near-pole packing fixture. Do not change only
the CPU preview helper. Single-drawing stroke tessellation can also cross the pole
through width offsets outside the reference box.
