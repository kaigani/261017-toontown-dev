## Consolidated residual risks for C0.4 and M3/M4

- Close R3-01 before C0.3 sign-off; distinguish complete observations from unavailable cadence estimates, and retain explicit legacy-log limitations.
- C0.4 still needs the accepted final arithmetic-policy decision; pinned scalar f32 is the bounded candidate, with lockfile/compiler/golden upgrade gates. No SSE-only hardware evidence exists.
- Actual user Mac, supported OS/WebKit floor, Retina/multiple displays and weaker GPUs remain unmeasured; virtualized CI is not hardware-floor coverage.
- Complete the M3 adapter matrix for transformed/mirrored/image/alpha paints, inverted clips, effects/flatten layers, blur, colour-transform order and straight-alpha export conversion.
- Keep the documented u8 opacity limit and independent ttraster reference; matching finite-corpus hashes do not establish all rendering correctness or universal determinism.
- M4 must implement painter order, correct translucent joins/caps, zoom-sensitive flattening, dirty geometry and main-thread decode/upload stall management.
- Residency needs real host delta measurements, stable identities/revisions, batching/backpressure, resync and overlays while retaining one authoritative logical render list.
- Compare reduced-performance host bitmaps with webview software rendering; native wgpu remains an integration hypothesis. Set export latency/memory/cancellation budgets from production-density scenes, effects and encoding, not area extrapolation.
