# `src/ipc` — the only path from the front end to the Rust host

- `transport.ts` — `HostTransport`: `invoke(command, args) → Promise<unknown>` and `listen(event, handler)`.
  Transports deal in `unknown`; nothing is trusted until `hostApi.ts` validates it.
- `tauriTransport.ts` — the Tauri implementation. **The only file allowed to load the Tauri packages, and only
  `index.ts` may import it.** Enforced by the bundler (`../../boundary/vite-plugin.ts`, dev/build/Vitest) and by
  the linter (`../../boundary/eslint.js`, every JS/TS extension, no inline ESLint configuration). See ADR-0001.
- `mockTransport.ts` — in-memory host for tests and for `pnpm dev` in a plain browser.
- `hostApi.ts` — the typed API UI code uses (`ping`, `appInfo`, `onMenuCommand`, M0 diagnostics). Product values
  cross as **JSON text** both ways (ADR-0012): arguments go as `{json: <text>}`, the host answers with JSON text (a
  UTF-8 body or a string), rejects with the JSON text of an `ErrorInfo` and emits events as JSON text. Text is parsed
  losslessly and validated; objects from in-process transports go through `certify`. Errors map to `HostError`
  (stable dotted `code`, 11 §10).
- `wireJson.ts` — strict, lossless JSON parser and writer: integers beyond 2^53 − 1 are `bigint`, objects are built
  with defined own keys; duplicate keys, unpaired surrogates, depth > 128 and integer literals the engine could not
  hold exactly are errors, exactly as in the engine's reader (shared corpus `tests/fixtures/wire/hostile-json.json`,
  `wireCorpus.test.ts`); schema-directed coercion (through conditional branches) turns digit-only doubles back into
  numbers.
- `schema.ts` — the JSON Schema validator (draft 2020-12 keywords used by the generated schemas, `$ref` through a
  definitions table, bigint-aware integers; own-property semantics only, exact-index arrays, own plain-data copy)
  and `certify` (plain data, structured-clone probe through `MessageChannel` that rejects every Proxy, validated
  snapshot). Safari 15.0 floor, ADR-0005.
- `generated/` — **generated, do not edit**: `wire.ts` (engine wire schemas and types) and `model.ts` (object-model
  schemas and types), regenerated by `TT_UPDATE_GOLDEN=1 cargo test -p tt-engine --test frontend_schemas`, which
  also fails CI when they drift from the Rust types.
- `wireSchemas.ts` — guards for the product wire values built on `generated/wire.ts` (plus the M0 diagnostics plan).
- `types.ts` — wire types: product types re-exported from `generated/wire.ts` (`EngineInfo` spelled out with a
  compile-time proof that it equals the generated type); M0 diagnostics and spike types hand-written.
- `context.ts` / `react.tsx` — `HostProvider` and `useHost()`.

Swapping the shell means writing another `HostTransport`; no UI code changes.
